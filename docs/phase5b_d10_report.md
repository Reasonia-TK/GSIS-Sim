## 1. 結論

1. **本実装の数値の誤差は小さく、差を説明しない。** 速度格子(Δξ = 2/3 → 1/2 で +0.03%、範囲を広げて 0.00%)、
   メッシュ(1.5 倍細かくして +0.20%、槽・管の出入口を細かくして −0.05%)、入口の接線速度(0.00%)は、どれも 0.2% 以下。
   円を 64 角形で近似した断面積の不足(−0.16%)は Ṁ を 0.26% 小さく見せている(Ṁ ∝ A^1.6)。メッシュと面積の誤差を除くと、本実装の GSIS-PBC は
   **0.338** 付近に収まる。どれも Ṁ を**大きくする**向きで、論文・DSMC との差は縮まらない
2. **論文の GSIS-PBC(0.326)との差の主な原因は、GSIS の不動点がマクロ(PBC)の離散化に依ること**と考える。
   論文の PBC の離散化(式 (30) のセル中心の HoT、式 (27)(28) のドナーセルの移流項)にすると、本実装でも
   ε < 1e−5 に収束したまま、HoT だけで −0.7%(本番のメッシュ)、移流項 1 次で入口 +2.6%・出口 −1.6%、両方で
   入口 0.344・**出口 0.328** になる(運動論の不動点からずれ、質量の保存も満たさない「循環」が不動点になる)。
   論文の中心線は、CIS の記号が本実装とほぼ重なり(p で +0.4%)、GSIS の線だけが p で 2% 低い。論文の CIS(0.348)と
   GSIS(0.326)の 6.7% の食い違いも同じ大きさで、論文の δ=10 の Ṁ には ±3% ほどの離散化・評価の幅があると見る
   (論文の 2 つの値の平均 0.337 は本実装と同じ)
3. **DSMC(0.32773)との差 +2.8% も、本実装の数値の誤差では説明できない。** 計算で切り分けたのは、(a) DSMC の入口
   (静止した槽から粒子を入れる)で上流槽の圧力が 0.2〜0.4% 低いこと(dlnṀ/dlnδ = 0.43 から DSMC の Ṁ で −0.3〜−0.55%)、
   (b) 本実装の GSIS の不動点が運動論の不動点(CIS 単独の収束解 0.3355〜0.3363)より +0.2〜+0.4% 大きいこと
   (多角形の面積 −0.26% とほぼ打ち消し合う)。残る約 2〜2.5% は、モデルの違い(Shakhov と VHS。すべり・クヌーセン層の
   輸送)と、DSMC の実効粘性が設定より大きいこと(格子・時間刻み、VHS の粘性の式。見積もりで DSMC の Ṁ −0.4〜−0.9%)に
   よると推測するが、本実装だけでは分けられない。断面の分布でも、同じ圧力・圧力勾配で本実装の方が 2〜3% 多く流れている
4. δ = 1・100 でも、セル中心の HoT は Ṁ を下げ(δ=1 の入口で −1.45%(本番の 1/4)、δ=100 で −0.95%(粗い)・
   −0.6%(フェーズ 5a の全体))、移流項 1 次は入口と出口を食い違わせる(δ=100 で PBC の入口 0.899・出口 0.886)。
   面積の影響は Ṁ ∝ A^1.5(δ=1)、A^1.3(δ=100)

## 2. 方法

### 2.1 1/4 領域

管は軸対称なので、y = 0・z = 0 の対称面 2 枚で切った 1/4 領域(DSMC `d10_q` と同じ)で計算すれば、同じ VRAM で
4 倍のセル・4 倍の速度点を使える。`make_mesh.py --quarter` は本番のメッシュと同じ関数(`gsis_tools.geometry.tube.tube_hex_elements`)
で全体の六面体メッシュを作り、y > 0・z > 0 のセルだけを残して y = 0・z = 0 の面をパッチ `sym_y`・`sym_z` にする
(n_theta が偶数なら O 型格子の節点の面がこの 2 面に乗る)。ソルバーの対称面(運動論は鏡映反射、PBC は流出流束の鏡映)は
既存の機能で、速度格子の y・z の範囲は 0 に対して対称(点数は偶数)である必要がある。$\dot M$ は 4 倍して全体の値にする。

| 計算 | セル | 反復 | $\dot M$ 入口 / 出口 | 時間 |
|---|---|---|---|---|
| 全体 `tube_hex`(フェーズ 5a の `runs/phase5/gsis/final_d10`) | 135,104 | 8 | 0.33698 / 0.33693 | 273 s |
| 1/4 領域 `q_base`(同じメッシュの 1/4) | 33,776 | 9 | 0.33700 / 0.33698 | 145 s |

差は 0.01% で、中心線の p・u_x も 1e−4 まで一致する(`results/profiles/`)。以下の感度の計算は 1/4 領域で行った。
時間は GPU を他の計算(5b-1 の試験、別のプロセス)と分け合った値で、同じ計算でも 1.5〜2 倍ばらつく。

### 2.2 計算の設定

既定はフェーズ 5a の δ = 10 の本番の設定(`cases/tube_vacuum/phase5/tube_delta10_p5.toml`: CIS は octant・内部反復 4 回 +
壁の更新・ブロック間の反復 2 回・保存的な離散平衡・負値 blend、PBC は移流項 2 次・面の HoT・境界面の再構成 limited、
補正のフィルタ ℓ = λ、局所 Kn > 1 の凍結、入口の流入の接線速度 0、N_CIS = 5・M = 10・CFL = 500・ε < 1e−5)。
各ジョブはここから 1 つ(または表に書いた組)だけを変える。初期化はどれも一様な状態 → PBC 単独(NSF)50 回 → f^eq。
`s` で始まるジョブは粗い 0.75 倍のメッシュ(`q_r075`、全体相当 66,144 セル)の計算で、VRAM 2 GB 未満なので
GPU の順番待ちなしで流した(傾向を先に見るため。主な結論は本番の 1/4 で確かめた)。

- DSMC は本実装より p が 1.1%、u が 2.8% 低い

### 4.3 入口の境界条件

| ジョブ | 変えたもの | 反復 | Ṁ 入口 / 出口 | 基準比 |
|---|---|---|---|---|
| `s75_tanext` | 入口の流入の接線速度を外挿(論文の式 (65)。基準は 0) | 9 | 0.33603 / 0.33599 | +0.00% |

- 入口の接線速度は効かない。入口は管から 8R 離れ、入口面の流速は u_x = 0.0021√(RT0)(0.0015√(2RT0))しかない
  (`q_base` の入口面の平均: ρ = 0.999998、T = 1.000002)。圧力入口の法線速度の補正 Δu = (p_ib − p_in)/(ρc_s) を外す

  0.3288〜0.3295(DSMC の解析の目安 0.32867 は傾き 0.33 で入口面の圧力を使った値)

## 5. 考察: 差の主な原因

### 5.1 論文の GSIS-PBC(0.326)との差 +3.4%

| 要因 | 本実装での大きさ | 向き |
|---|---|---|
| 速度格子(Δξ = 2/3) | < 0.05% | 本実装が小さい |
| メッシュの離散化(本番の 1/4) | 約 −0.1% | 本実装が小さい |
| 円の多角形近似(64 角形) | −0.26% | 本実装が小さい(論文のメッシュの多角形は不明) |
| 入口の接線速度(0 ↔ 外挿) | 0.00% | — |
| PBC の離散化(論文の式 (30) のセル中心の HoT) | −0.7%(本番) | 論文の値を下げる |
| PBC の離散化(論文の式 (27)(28) のドナーセル) | 入口 +2.6%・出口 −1.6% | 測る場所で ±2〜3% |
| 両方 | 入口 +2.1%・出口 −2.6%(0.328) | 出口なら論文の値にほぼ一致 |
| 凍結なし・負値の置換(論文どおり) | PBC −1.2%、運動論の出口 +1% | 測る場所で ±1% |

- 本実装の数値の誤差(速度格子・メッシュ・境界条件)は 0.4% 以下で、どれも本実装の Ṁ を小さく見せる向き。差は縮まらない
- 論文の GSIS-PBC は、論文が書いているとおりのマクロの離散化(セル中心の HoT、ドナーセルの移流項、凍結なし、置換)では、
  GSIS の不動点が運動論の解から数 % ずれ得る。本実装で論文の離散化にすると、出口の Ṁ が論文の値(0.326)に、入口の Ṁ が
  論文の CIS の値(0.348)に近い値(0.328 / 0.344)になる。論文の中心線(GSIS の p が CIS より 2% 低い)も、
  GSIS の不動点が運動論の解からずれていることと合う
- したがって、論文との差の主な原因は**論文側の GSIS の不動点の偏り(マクロの離散化による)**と考える。ただし論文のメッシュ・
  リミッタ・Ṁ の評価の場所は書かれていないので、これは「本実装で論文の離散化を真似ると同じ大きさ・向きの差が出る」という
  状況証拠である(推測を含む)

### 5.2 DSMC(0.32773、論文の DSMC 0.330)との差 +2.8%

| 要因 | Ṁ への影響(DSMC を本実装にそろえる補正) | 根拠 |
|---|---|---|
| DSMC の入口(静止した槽から粒子を入れる)で上流槽の圧力が 0.996〜0.998 | DSMC を +0.3〜+0.55% | 計算(dlnṀ/dlnδ = 0.43) |
| 本実装の多角形近似(64 角形 ↔ DSMC の等面積 128 角形) | 本実装を +0.26% | 計算 |
| 本実装の GSIS の不動点の偏り(運動論の解より大きい) | 本実装を −0.2〜−0.4% | 計算(本番の 1/4 で +0.2〜+0.4%、粗いメッシュで +0.4〜+0.6%) |
| 本実装のメッシュ・速度格子の誤差 | 本実装を +0.1% | 計算 |
| DSMC の格子・時間刻み(Δx/λ ≈ 1、MCS/λ ≈ 0.25、c̄Δt/λ ≈ 0.2〜0.3)による実効粘性の増加 | DSMC を +0.2〜+0.5% | 見積もり(文献の誤差の式、推測) |
| VHS の粘性の式(Chapman–Enskog の第 1 近似)と実際の VHS の粘性の差(ω = 0.66 で 0.5〜1%) | DSMC を +0.2〜+0.4% | 見積もり(推測) |
| 残り(Shakhov と VHS の運動論の違い。例: 粘性のすべり係数 σ_P は BGK・S モデルで約 1.016、剛体球の線形 Boltzmann で約 0.99 と言われ、S モデルの方がすべりが 3% ほど大きい。数値は文献の記憶による目安で、本調査では確かめていない) | 約 +1.5〜2% | 推測(本実装では切り分けられない) |

  引くと 0.3369〜0.3375、CIS 単独 0.3355〜0.3363 にメッシュと面積の補正 +0.36% を足すと 0.3367〜0.3375)、

## 6. 提案

コードの変更(統括役・5b-1 への提案。自分では変えていない):

1. **収束の判定に質量の釣り合いを加える**: ε < 1e−5 でも、入口と出口の Ṁ(運動論・PBC)が数 % 食い違う不動点がある(§4.4)。
   summary.json に「入口と出口の Ṁ の相対差」「補正の後の f と PBC の Ṁ の差」を出し、閾値(例 0.2%)を超えたら警告する
2. **PBC の既定値**: GSIS の段は移流項 2 次(`[macro].advection = "upwind2"`)と面の HoT を既定にする(`advection` のコードの
   既定は今 `upwind1`。管のケースは TOML で 2 次を指定している)。1 次は GSIS の不動点を ±2〜3% 動かす
3. **管内の断面の質量流量の出力**: 管の中の x の断面を通る離散的な質量流束(面の和)を出す。入口・出口の境界の流量は
   上流槽の遅い振動(CIS 単独)や置換(負値の処理)で揺れるが、断面の流量は安定で、DSMC の ṁ(x) とも直接比べられる
4. **メッシュ生成の等面積の選択肢**(Python、`gsis_tools.geometry.tube`): 正多角形の頂点を R/√(面積比) に置いて断面積を円と
   そろえる(DSMC の形状と同じ)。本番の 64 角形は Ṁ を 0.2〜0.26% 小さく見せる。本調査では `make_mesh.py --equal-area` で代用
5. **DSMC と同じ形の入口**(任意): 静止した Maxwell 分布を流入させる境界(`[[boundary]].type = "reservoir_inlet"` のような)。
   DSMC との比べ方が単純になる(今は換算で −0.3〜−0.55%)

追加の計算(コードを変えない):

6. DSMC の感度計算 `d10_q_ppc14`(約 1 時間)・`d10_q_dt`(約 3 時間)。DSMC の格子・時間刻みの誤差を測り、§5.2 の
   見積もりを計算に置き換える
7. モデルの違いの切り分け: 長い管の線形の Poiseuille 流れ(小さな圧力差)の流量係数 G_P(δ) を本実装で計算し、Sharipov の
   S モデル・剛体球の表と比べる(Shakhov と Boltzmann の違いの大きさが δ ごとに分かる)

## 7. 未解決の点

1. 論文の GSIS-PBC が実際にどの Ṁ(入口・出口、運動論・PBC)を報告したか、論文のメッシュ(多角形・セルの形)は分からない
2. DSMC との残り約 2% がモデルの違いか DSMC の数値の誤差かは、本実装だけでは分けられない(§6 の 6・7)
3. 四面体のメッシュ(`full_tet`)は流していない(全体のメッシュで VRAM 約 13 GB。共用の GPU で他の小さな試験と重なると
   載らないおそれがある)。論文のメッシュの形が分からないので、セルの形の影響は確かめていない
4. 流していない(優先度を下げた)もの: PBC の境界面の再構成をセルの値(`q_brcell`。フェーズ 4・5a で GSIS の不動点を
