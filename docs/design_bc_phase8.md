# フェーズ8 S3: Maxwell壁と質量流量入口

## 1. 運動論のMaxwell壁

法線nは気体から外向き、壁速度は接線方向とする。入射速度 ξ·n<0 に対し、Rξ=ξ−2(ξ·n)n と置く。境界分布は

`f_minus(ξ)=s M(1,u_wall,T_wall;ξ)+(1−α) I[f_plus](Rξ)`、`s=αρ_wall`。

離散の流出質量流束をJ_plus、単位密度Maxwell分布の流入質量流束をJ_M<0、補間した鏡面分布の流入質量流束をJ_S<0とすると、

`s=−[J_plus+(1−α)J_S]/J_M`。

これにより速度格子・補間誤差も拡散部分の密度で打ち消す。負のsが必要になるほど粗い速度格子では正値性とこの式を両立できないため、明示的なエラーとし、速度格子の細分化を求める。α=1は既存の拡散壁と同じ種別・計算経路にする。

補間案は最近傍、三線形、高次多項式を比較した。最近傍は回転角に対して不連続、高次は負値と広いステンシルを生むため、非負の重みを持つ三線形を採用する。ただしf自体の三線形補間は傾斜壁で人工的な加熱を生んだため、最終方式は局所の平衡分布M_cで規格化した値の三線形補間とする。すなわち`I[f](r)=Σ_k w_k f_k M_c(r)/M_c(ξ_k)`。比は指数の差から計算して裾の0/0を避ける。これにより等温静止の平衡分布を保ち、非負の重みも維持できる。通常の三線形は40³格子の傾斜クエット流で温度に約1.9%の偏りを生んだが、規格化版ではRMS 5.8e−5へ減った。

反射先が中点格子の外なら分布を0とする。これは速度空間の切断であり、十分広い範囲で裾が無視できることを検証する。各補間点では既存の空間再構成を使用する。勾配用の境界値はセルの分布を速度補間した1次値とし、再帰的な勾配評価を避ける。質量以外の離散モーメントを厳密には保存しないので、角度と速度格子に関する収束確認は必要である。

軸方向法線では対称面と同じ鏡映対応を使い、補間しない。鏡面反射は接線方向の壁速度に依存しない。一般形状のパッチは面ごとに軸判定する。

反復の初めに鏡面流入分布を全速度点について作り、全チャンクのスイープ中は固定する。これによりチャンク順の影響を避ける。追加配列は部分適応壁の面数B_Mに対して`2*B_M*Nv*sizeof(F)`、面の対応と係数`16*B`、速度格子の逆対応`4*Nv` bytes。壁がなければ確保しない。ホストには単位密度壁の半空間モーメント`80*B` bytesを初期化時に保存し、反復ごとの全速度積分を省く。勾配用は最大8点、2次の鏡面キャッシュ構築は最大8回の既存空間勾配を要し、軸方向は1回で済む。CUDAは16面×速度128点のブロックに分割し、長時間の単一カーネルを避ける。メモリ見積もりに追加配列を含める。

## 2. PBCとGSISの境界流束

上記2本のキャッシュは勾配用の1次反射と流束用の2次反射に対応する。まず全ての1次反射を作り、その固定値を使って全ての2次反射を再構成する。inner_wall_updateでは内部スイープの間に両方を更新するが、各スイープ中は変えない。通常のf三線形に比べて補間点ごとの指数比の計算が増え、一般法線では各点最大8回の空間再構成と追加の速度読取りを要する。軸方向は鏡映した1点だけを使う。

単位密度の壁Maxwell流束H_minus、`h=−H_minus_mass=A sqrt(T_wall/(2π))`、鏡映流束作用素M(質量・エネルギーは符号反転、運動量は`2 n n^T−I`)とすると、付録B.2の一般化は

`T_minus(F_plus)=α H_minus F_plus_mass/h+(1−α) M F_plus`。

その質量成分は常に`−F_plus_mass`。壁の接線運動量・エネルギー交換はα倍、鏡面部分は法線運動量のみ交換する。接線方向に動く壁でも鏡面部分のエネルギー輸送は符号反転する。

付録C.2のヤコビアンは`J_b=[I+α(H_minus/h)e_mass^T+(1−α)M] J_plus`。直接のW依存項はない。既存の拡散壁ヤコビアンと対称面ヤコビアンの凸結合で評価できる。

GSISでは段の初めに離散の`F_plus0,F_minus0,W_b0`から、既存と同じ`C_plus=F_plus0−T_plus(W_b0)`、`C_minus=F_minus0−T_minus(F_plus0)`を作り、段の間は固定する。三線形補間・離散積分・空間再構成の差もC_minusに含め、段の初期流束は運動論と一致させる。面の密度モーメントも拡散と鏡映の凸結合とする。

NSF単独では微視的なすべり長を別途導入せず、同じ半空間Maxwell混合のPBC境界を用いる。これは有限セル幅の運動論型境界であり、連続体のMaxwellすべり・温度ジャンプ条件の高精度な実装とは区別する。NSF単独の適応係数依存精度は保証しないことを警告する。

## 3. 質量流量入口

流入正の目標を無次元化し、既存の圧力入口として扱う。初期`p_b=p_ref`。目標はパッチ全体の量であり、面ごとに一様な流量は指定しない。

候補は比例比率`p_b*=target/current`、割線法、正の局所感度を用いた緩和更新。比率法は逆流・ゼロ流量で破綻し、割線法は未収束の内部場の変動を圧力感度と誤認するため、局所感度案を採用する。

運動論のスイープ前に、現在のfから測った流入量Qを使い、`p_b_new=max(p_floor,p_b+0.2*(Q_target−Q)/D)`、1回の変化はp_bの±10%に制限する。Dは音響圧力入口と半Maxwell流束から見積もる正の感度で、各面の`A[1/sqrt(2πT_b)+1/(2sqrt(gamma*T_i))]`を加える。厳密Newton微分ではなく、内部場の応答を反復に任せる安定化した更新である。

prepareや出力のみの呼出しでは圧力を変えない。GSISでは外側反復の初めに補正後fの流量を使って1回だけ更新し、続くCISとPBCの両段の間は同じp_bに固定する。CIS後の流量だけを制御すると、PBC補正が有限に残る場合に補正後流量の目標と食い違うためである。NSF単独ではマクロ反復ごとに同じ更新を行う。最終の流入量相対誤差`abs(Q−Q_target)/Q_target<=1e−3`をCLIの収束の必要条件に加える。GSISでは補正後fの流量を判定に使う。

履歴は対象パッチのみ`p_b_<patch>_Pa`を追加し、summaryの対象patchに`pressure_Pa`・`target_mass_flow_kg_s`・`mass_flow_relative_error`を追加する。check-caseの対象patchにも初期pressureと目標流量を追加する。既存キー・列・値は維持し、保存性診断で入口として数える。自動速度格子は温度と任意の壁速度を従来と同じ式で拾う。

## 4. 参照解と確認

ref1dでは壁の入射分布をα倍の壁Maxwell分布と(1−α)倍の法線速度反転分布の和にする。縮約分布の全成分を同じ鏡映で移す。単位密度壁の流束から密度を決め、α=1の演算順は保つ。

検証はα=1同値、部分適応壁のCIS/GSISとref1dの熱流束・せん断応力・プロファイル、回転した六面体平板、管δ=10の入口圧力回復、既存六面体管δ=1/10の回帰を行う。実測と限界はS3報告に記録する。
