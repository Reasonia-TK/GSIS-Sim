# フェーズ8 S1: 四面体メッシュでの頑健性

## 結論

S1の受け入れ条件は未達。133,586セルの四面体でCISはδ=1・10とも式(59)の収束条件を満たし、入口・出口の流量は六面体GSISの各値から1%以内だった。ただし質量保存の警告が残る。GSISはδ=1で設定を変えて残差が収束しても補正後の入口流量に17.6〜30.5%のずれが残り、δ=10ではPBC境界の不安定性を確認し、両側cellで初期発散を防いでも流量に約2%の差を残した。残差だけを根拠に成功としない。

正値性リミッタの組合せの不具合を修正し、固定した分布関数に対する境界反復の調査機能を追加した。全体の既定値は変更していない。依存追加、Pythonコードの編集、commit・pushは行っていない。

## やったこと

- `CLAUDE.md`、フェーズ8設計、進捗・仕様、フェーズ2・再現レポートを確認し、現行実装と照合した。
- 既存の `gsis_tools mesh tube` で25,387セルの四面体を生成し、発散の再現と設定の切り分けを行った。
- 既存の本番四面体133,586セルでCISとGSISのδ=1・10を計算し、流量、断面、中心線を六面体と比較した。
- 正値性制限と `limiter="none"` の組合せ、固定fの境界更新を修正・検証した。
- GPU計算を `runs/.gpu_lock` で直列化し、CLI引数、出力、終了コードを保存した。メタデータ記録を段階的に追加し、後半の計算ではケース・exeのSHA256も保存した。

## 実装した変更

### 正値性リミッタ

旧実装では `limiter="none"` の早期returnで `positivity_limiter=true` も無効になっていた。両者を独立にし、正値性を有効にした非正値セルでは勾配を0にした。セル値そのものの負値は隠さない。

歪みのある四面体の全ての面中心をFP32/FP64、none/absolute/relativeで調べ、正のセル値からの再構成が丸め誤差内で非負になることを確認した。四面体でのGPU/CPU一致とGPUの決定性も検証した。

**この修正だけが通常のVenkatakrishnan設定の四面体発散を解決したわけではない。** 従来から存在した正値性制限を有効にし、速度ごとの擬似時間CFL=5を併用してCISの安定性を得た。制限は面への再構成に対するもので、Shakhov目標分布やLU-SGSの更新全体の非負性を保証しない。

### 固定fの境界反復

`[kinetic].boundary_iterations` (整数1〜1000、既定1)を追加。セルのfを変えず、圧力流入分布→半空間集計→壁密度・境界モーメントを反復する。最小二乗の再構成には境界の状態が入り、同じセルに接する壁・圧力面の評価が互いに依存するため、従来の1回の遅れ評価と反復した値は一般には一致しない。

既定1は従来の計算順をそのまま保つ。単体試験では、8回をまとめた評価とゼロ補正を挟んで1回を8回評価した結果が一致し、fが変わらないことを確認。64回の結果を基準にした境界モーメント誤差は、8回で1回の1/10未満になった。これは一つの歪み四面体箱での確認であり、任意形状での収束保証ではない。

本番δ=1の両側cell/境界8回 (`full_d1_gsis_matched_cell`) は54回、ε=8.910e-6で収束扱いとなったが、補正後の入口・出口不釣り合い17.99%/全断面ばらつき18.85%、流量平均0.181166は六面体平均から−8.90%。CIS後入口0.193412、PBC入口0.196960、補正後入口0.163261で、再構成を揃えるだけでも不整合を解消しないことを本番で確認した。PBC補正量1.876e-3、計算1,050.3秒。

本番δ=10の両側cell/境界8回 (`full_d10_gsis_matched_cell`) は41回でSTOP。速度のεが約3〜4e-5で変動し、ε=1e-5には未達。補正後の入口・出口不釣り合い0.460%/全断面ばらつき0.479%、PBC補正量5.192e-4。断面流量は0.329688〜0.330454、中央値位置x/R=13の値は0.329799で、同じ四面体CISの0.334722より約1.47%低い。マクロcellのみの17回の場と、中心線のp/u/T RMS差(六面体比)はほぼ同じだった。長く続けた場合の残差収束は未確認で、STOP時点の物理値として扱う。

### GSISで残った問題

本番δ=1、limited/CFL5の54回時点で、CIS後の入口は0.198621、PBC入口は0.199921、補正後fの入口は0.160828。出口は全て約0.199044、管の補正後断面は0.199049〜0.199834。マクロ場のノルムが収束しても、入口の補正後境界流束が整合していない。補正後fの入口・出口不釣り合い19.20%、全断面ばらつき20.13%であり、S1の合格とはいえない。

`apply_gsis_correction` はversionを更新し、`boundary_fluxes` は `prepare` を呼ぶことをコードで確認した。単純なキャッシュ更新漏れではなかった。式(59)は外側反復間のマクロ場の変化を見るため、CISとPBCが毎回有限な補正を相殺する状態を除外する判定ではない。今回の非零のPBC補正量と流量差はその切り分けが必要なことを示すが、分布関数全体の周期性を直接測ったわけではない。再構成の境界状態の遅れ、運動論/マクロの圧力境界再構成、式(14)の補正と非線形の制限・境界流束の整合性が次の調査対象。境界ヤコビアンを変えるだけではδ=10の不安定性は解消しなかった。固有モードの解析まではしておらず、機構の断定はしない。

同じNSF初期場から固定fの境界更新を8回へ増やした本番追試 (`full_d1_gsis_boundary8`) も54回でε=9.067e-6に達したが、補正後入口は0.137693へ悪化。CIS後0.198914、PBC0.200082、出口0.199048で、補正後不釣り合い30.82%/全断面ばらつき32.63%、PBC補正量は2.793e-3を残す (六面体δ=1の同指標は9.170e-5)。小規模での釣り合い改善を本番へ一般化できなかった。境界反復は診断用のopt-inとして残し、推奨値・既定値は変えない。単純な遅れの解消だけでは不十分という反証であり、非線形境界写像の安定性や内部の離散流束とPBC補正の整合性も調べる必要がある。

既存の `docs/design_gsis.md` §6にも、局所Kn>1の凍結でGSISの不動点が質量保存せず、六面体δ=1で入口と管に約0.55%の差を残す記録がある。今回は同じ凍結設定を維持しており、四面体の槽で凍結する領域と、境界再構成の影響を分離していない。`gsis_freeze_kn=0` と滑らかな `gsis.damp_kn` の比較は次の候補だが未実施。約18〜31%の差の全てを既知の0.55%と同じ機構とは断定しない。

また `docs/design_pbc.md` §11は、四面体・歪み六面体の製造解法で圧力が約1次となり、面の圧力に歪みの補正がないと記録している。境界だけでなく、内部の運動論とマクロの離散流束の整合性・歪み誤差も調査対象である。

## メッシュ差の見込み

壁面とx一定面の交線から求めた断面積の真円πR²に対する不足は、小規模四面体0.5055〜0.5090%、本番四面体0.1382〜0.1384%、六面体0.1606%。本番間の幾何差は約0.022%であり、GSIS入口の約19%の差を面積差だけでは説明できない。

小規模は本番より約0.35%余分に面積が不足する。有効半径と自由分子〜粘性のR³〜R⁴依存を仮定すると、流量約0.5〜0.7%の差の要因になり得る概算。厳密な補正値ではない。槽の粗密の違い、空間離散化、反復誤差、PBCの境界誤差を分離したメッシュ収束試験は未実施。詳細は `geometry_sections.json` と `mesh_regions.json`。

## 決めたことと理由

- 正値性false・境界反復1など既定値を維持した。未解決のGSIS境界誤差を残して一般設定へ広げないため。
- 四面体CISの比較は正値性+CFL5を明示。全域CFL1+n_cis20への変更や収束許容値の緩和は採用しない。境界反復は、fを変えずに遅れの寄与を再現して切り分けるopt-inとして残したが、今回の本番では有効な解決策にならなかった。
- Windowsでは実行中のexeを上書きできないため、baseline/candidate/boundaryを別ファイルに固定した。candidateは正値性修正のみ、boundaryは本報告の境界反復も含む最終実装。各実行のexecutable.jsonで判別する。
- メッシュ生成は1スレッドで行い、既存のメッシュは変更しない。Pythonの依存やソースは変更しない。

## 次の担当への引き継ぎ

1. δ=1の `full_d1_gsis_limited_cfl5` のCIS後/PBC/補正後fの入口の差を最小の四面体箱へ縮約し、式(14)前後の全半空間流束を突き合わせる。キャッシュ更新漏れとは分離済み。さらに十分収束したCISのfを保持したままPBCを1段評価し、同じ場で運動論の離散残差のモーメントとPBC残差を比較する。マクロCSVから平衡分布へ初期化し直すとfが変わるので、この切り分けでは同じプロセス内でfを保持する。
2. δ=1は凍結なし+滑らかな減衰の比較も行い、凍結領域と境界再構成の寄与を分ける。δ=10はcellで初期発散を防いでも管内流量の差が残るので、同じ場における運動論の内部面流束とPBCの流束・離散残差を突き合わせ、圧力の歪み補正を含む整合性を調べる。limited境界の安定化も、単なる正値性・CFL低下・Jac再構成・連続式擬似時間の追加だけでは解決していない。
3. CISの反復誤差を保存性も使って収束させ、その後に槽を含むメッシュ依存性を評価する。VRAM予算内で、過度に細かい管のセルを槽へ配分し直す比較も候補。今回の1%以内を真の誤差限界とはしない。
4. 数値手法の変更を採る場合は同じ初期場・速度格子で六面体δ=1・10を再検証し、旧設定の再現性を保持する。
