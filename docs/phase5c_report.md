- 3 条件とも式 (59) の ε < 10⁻⁵ を満たしたうえで、許容値 0.2% を超える釣り合いの残りを警告した
- δ=1: 管の中の運動論の断面はそろっていて(0.1993〜0.1995)、入口だけが小さい(次の項目の続けた計算で、収束待ちではなく不動点の
  食い違いと分かった)。管を通る流量 0.1994 はフェーズ 2 の CIS 単独を ε < 10⁻⁷ まで回した値と同じ。PBC の断面が 0.1982〜0.1998 と
  そろわないのは、管と下流槽のほぼ全体が凍結(局所 Kn > 1)していて、凍結したセルの状態(W^{n+1/2} のまま)で評価した PBC の
  フラックスが PBC の連続式を満たさないため(x = 8 の断面は PBC で動かす上流槽との境目で、入口と同じ 0.1982)
- δ=1 を `--set gsis.mass_balance_required=true`(f^{n+1/2} の入口と出口の差 < 0.2% も判定に加える)で続けた計算
  (`runs/phase5c/gsis/d1_mb`、NSF の初期場から): ε は 42 回目に 9.5 × 10⁻⁸ まで下がったが、f^{n+1/2} の差は 25 回目から 0.22〜0.27% で
  頭打ちになり(最後の f は 0.55%、PBC は 0.56%)、判定を満たさないので STOP で止めた。最後の状態では管の 5 つの断面の流量が
  0.19942 でそろい、出口と同じ。入口(0.19833)と PBC の入口側の断面(x = 8 で 0.19830)だけが小さい。→ δ=1 の差は収束待ちではなく、
  GSIS の不動点の食い違い: PBC で動かす上流槽(凍結しない)と、凍結した管・下流槽(運動論だけ)の境目で、補正が上流槽に PBC の流量
  (0.1983)を課し、管の中の運動論の流量(0.1994)と合わない。局所 Kn > 1 の凍結(論文との違い 3)の副作用。δ=1 の Ṁ は管の流量
  **0.1994** と見るのがよい(フェーズ 2 の CIS 単独を ε < 10⁻⁷ まで回した値 0.1994 と同じ)
- δ=10: PBC の解は保存(断面がすべて 0.33697)。運動論の断面は ±0.2% ばらつく(GSIS の不動点では PBC 段が毎回 W を
  2 × 10⁻⁴ 動かし、補正の後の f は運動論の定常解から少しずれる。最後の f の X = 0 の断面 0.33778 は補正の分で、f^{n+1/2} では 0.33685)
- δ=100: PBC の断面は管の中で一定(0.89203)で入口と同じ。出口との差 +0.38% は凍結した下流槽(噴流の膨張部)で生じる。
  補正の後の負値の混合が毎回 1.4 万セルで続く(下流の噴流)。管を通る流量は 0.8920

  δ=10 は ε < 10⁻⁵ の時点で入口の流量が 31% 小さい「見かけの収束」(上流槽が質量を失っている途中)
- δ=100(一様な初期状態から): 1,000 回目でも管の入口の断面の流量は 0(X = 5 で 0.159、X = 10 で 0.806)、1,600 回目で X = 0 が 0.177。
  連続流の領域では Δt = ∞ の CIS が 1 回で衝突時間の分しか状態を動かさないので、流れが上流へ広がるのに数千回かかる。ε は 600〜900 回目に
  一時 0.01 まで上がり(流れの先端が管を進む間)、その後 1.2 × 10⁻⁴ までゆっくり下がった。3,000 回の予定を 1,600 回で打ち切った
  (GPU の時間。この先も入口の流れの成立に数百回以上かかる見込み)
- δ=100(NSF の初期場から): 192 回で ε < 10⁻⁵ を満たしたが、これも見かけの収束。管の断面の流量が X とともに 3.4% 減り(入口側が多い)、
  管の中に質量がたまっていく途中(中心線の p は GSIS より 0.6〜3% 低く、u_x は 2〜4.5% 大きい)。ε は 50 回目 1 × 10⁻⁴、100 回目
  2.6 × 10⁻⁵ の後ゆっくり下がり、その間に断面の流量はほとんど変わらない(遅いモード)。出口で測ると 0.8675(論文の GSIS に −2.0%、
  本実装の GSIS に −2.8%)、入口で測ると 0.9007(+1.0%)
- 論文の CIS の δ=100(2,796 回、0.597、Fig.3 の中心線は管の全体で流れがある)は、本実装の一様な初期状態からの計算とも、NSF の
  初期場からの計算とも合わない。
  論文の CIS の初期状態・解き方は書かれていないので、反復数の比較は桁の目安にとどめる

| 本番 + 周方向を 2 倍(n_theta 32) | 333,184 | 0.045R | 97 | 147 s | 1.3187 | +3.4% | +4.1% |

- 断面積を円と同じにした差は +0.18%(本番)→ +0.03%(2.5 倍)。1 次の移流項は 2 次より 1.3〜1.5% 小さく、同じ極限に向かう。
  槽(−0.07%)・管の出入口(−0.01%)を細かくしても変わらず、周方向の 2 倍は +0.56%(壁際のセルの形が変わる)

- **細かくするほど Ṁ は大きくなり、論文の値から離れる。** h に対してほぼ 1 次(h = 1 → 0.4 で傾き dṀ/dh ≈ −0.07 がほとんど
  変わらない)で、h → 0 に外挿すると約 1.375〜1.38(1.25〜2.5 倍の 5 点に M∞ − C h^p を当てはめて 1.375・p = 1.2、細かい 3 点で
  1.382・p = 0.94。論文の GSIS に +8%、NS に +9%)。壁の最初のセルだけの細分化を外挿すると 1.365
- **メッシュ依存性の大部分は壁の最初のセルから来る。** ほかを変えずに壁の最初のセルだけを 1/8 にすると +3.8%(1.311 → 1.361)。
  断面の分布では、管の中心の ρu_x はメッシュでほとんど変わらず(X = 5 で 0.718〜0.720)、壁際(r > 0.9)の ρu_x が細かくするほど
  大きくなる(0.097 → 0.136)
- 仕組み: 単独モードの PBC の壁の境界フラックスは、壁際のセルの状態(`standalone_boundary_reconstruction = "cell"`、勾配の境界値も
  セルの値)の半空間 Maxwell 流束(式 (33)–(38)、整合補正なし)なので、壁のせん断は τ_w = ρ√(RT/2π) u_c(u_c はセル中心の接線速度)。
  NS の滑りなしの τ = μ u_c/d(d は壁からセル中心までの距離)と比べると τ_w/τ = d/(2λ)(λ = (μ/p)√(πRT/2)、式 (8))で、本番の
  メッシュの入口の状態では d ≈ 0.022R、λ ≈ 0.0009R なので約 12 倍の壁の抵抗になる(壁から d − 2λ だけ内側に壁があるのと同じ)。
  h → 0 の極限は滑りの長さ 2λ の滑り境界の NSF(拡散反射の粘性の滑り係数 σ_P ≈ 1.0(BGK・S モデル、等価平均自由行程
  (μ/p)√(2RT) 基準)から見積もる滑りの長さ約 1.15λ の 1.7 倍程度。係数は文献の記憶による目安)。論文の GSIS-PBC では、不動点の境界フラックスは
  運動論の解の境界の離散流束(整合補正 C^±)なので、この単独モードの誤差は GSIS の初期値にしか効かない
- 2 次の壁の扱い(勾配の境界値を壁の境界面の分布のモーメント、境界面の値を制限付きの再構成)も試したが、収束した解から始めても
  CFL 1〜500 のどれでも 13〜21 回目に発散した(フェーズ 3 の「単独モードの制限付きの再構成は発散しやすい」と同じ)
- **結論: 本番のメッシュの +2.8% は「メッシュが粗いための過大評価」ではない。** メッシュの 1 次の誤差(約 −5%、うち壁の最初のセルが約 −4%)と、
  メッシュを細かくした NSF(運動論の滑り境界)と論文の GSIS の差(約 +8%)が打ち消し合った値。メッシュを細かくすると論文から離れるので、
  δ=1000 の Ṁ の差(GSIS の未収束の 1.331、+4.4%)を本実装のメッシュの粗さで説明することはできない。残りの差は、壁の滑り
  (本実装の NSF の極限は滑りあり、FLUENT の NS は不明だがふつうは滑りなし)、論文のメッシュと数値の扱い(書かれていない)など、
  本実装だけでは分けられない要因による
- 参考: 1 次の移流項は本番のメッシュで −1.5%(1.2918)

### 8.2 判断してほしい点

1. **質量の釣り合いの許容値の既定(0.2%)**: 最終の 3 条件とも警告が出る(δ=1: 入口と出口 0.66%、δ=10: 最後の f の断面のばらつき 0.45%、
   δ=100: 0.37%)。どれも実際の未収束・不動点のずれを示しているので 0.2% のままを提案するが、警告が常に出るのを避けるなら 0.5% も選べる。
   なお δ=1 は不動点そのものが 0.55% 食い違う(§2)ので、`mass_balance_required = true` では判定を満たさない。既定は false のままを提案する
2. **報告する Ṁ の値**: これまでの表は入口の値。断面の流量で見ると、δ=1 は管を流れる量が 0.1994(入口 0.1982 は凍結した領域の境目での不動点の食い違い。§2)、
   δ=100 は管 0.8920(出口 0.8953 は凍結した下流槽の分)。入口・出口・管の断面の幅で示すことを提案する(再現レポート §4)

   本番のメッシュの値を主に報告し、メッシュ依存性を併記する形でよいか。壁際の勾配の境界値の改善(運動論の流出側を片側の外挿にする
   など)を課題にするか
4. **δ=1000**: GSIS は未解決のまま(ユーザーの判断どおり)。NSF のみの PBC 単独の +2.8% はメッシュから来るものではなく、細かくすると
   論文から離れる(§5)。これ以上追うか
5. **移流項の既定の変更が `pbc-run` にも効く**: `[macro].advection` は GSIS の段と `pbc-run` で共通なので、`pbc-run` の既定も 2 次になった
   (初期化の `init_advection` は 1 次のまま)。`pbc-run` だけ 1 次の既定を保つ必要があるか
6. **CIS 単独の初期状態**: 論文の CIS の初期状態は書かれていない。δ=100 は一様な初期状態からでは 1,600 回でも流れが管に行き渡らず、
   NSF の初期場からは 192 回で ε < 10⁻⁵ を満たすが入口と出口が 3.7% 食い違う見かけの収束(§3)。どちらの初期状態でも論文の
   0.597・2,796 回は再現しない。再現レポートでは両方を示した。CIS 単独の比較をこれ以上追うか(釣り合いを判定に加えて回し続ける等)
7. 担当外の文書の更新(§8.1)と、統合のビルド `build/release` の作り直し(テスト 138 → 152 件)
