## 1. 役割と入出力(`KineticSolver`、`src/kinetic/kinetic_solver.hpp`)

入出力はすべて無次元量(spec §3.2、p = ρT)、セル・境界面は元のメッシュの番号。型は `src/gsis/interfaces.hpp`。

| 関数 | 内容 |
|---|---|
| `KineticSolver(config, mesh, geometry, params)` | 前処理と実行部分(`backend = "cuda"` / `"cpu"`、`precision = "fp32"` / `"fp64"`)の用意 |
| `initialize_uniform(ρ, u, T)` / `initialize_equilibrium(CellMacroState)` | f = f^eq で初期化(反復の番号を 0 に戻す) |
| `prepare()` | 現在の f^ℓ のモーメント、閉じた領域の全質量の規格化、式 (59) の ε、境界条件(圧力境界の W_b、拡散壁の ρ_Γ)の更新、境界の集計。記録 `KineticIterationInfo` を返す |
| `sweep()` | f^ℓ → f^(ℓ+1)(全チャンクの勾配・残差・LU-SGS・更新)。残差のノルムと時間の内訳を記録に足す |
| `moments()` → `KineticMoments` | 現在の f のモーメント(ρ, u, T, p, σ 6 成分, q。FP64) |
| `boundary_fluxes()` → `BoundaryKineticFluxes` | 境界面ごとの F⁺(流出側の再構成値の和)、F⁻(流入側の境界条件の値の和)、境界面の分布の [ρ, u, T](式 (35)、仮定 A7) |
| `apply_gsis_correction(W_half, W_new)` | 式 (14) の補正と負値の置換。置き換えたセル数を返す |
| `distribution()` / `set_distribution()` | 分布関数の読み書き(元のセル番号 × 速度格子の番号。テスト・保存用) |

CIS 単独は「`prepare` → 収束判定 → `sweep`」を繰り返す(`cis-run`)。GSIS(フェーズ 4)は N_CIS 回の `sweep` の後に `moments()`・`boundary_fluxes()` を取り、PBC の後に `apply_gsis_correction` を呼ぶ。

## 2. データの並び

| データ | 型・並び | 管ケースの大きさ |
|---|---|---|
| 分布関数 f | float(または double)、[セル(内部の番号)][速度点の保存位置] | 9.34 GB |
| 速度格子 | float の配列 ξx, ξy, ξz(保存位置の順)、重みはスカラー | 0.2 MB |
| セル → 面の CSR の要素 `CsrEntry` | 相手のセル(境界なら −1)、境界面の番号、外向き面積ベクトル S_out、x_f − x_i、x_f − x_j、最小二乗の係数 c_k(すべて無次元、FP32) | 45 MB |
| 境界面 `BoundaryFaceInfo` | 隣接セル、種類、鏡映の xor、パッチ、法線、面積、x_f − x_i | 0.5 MB |
| 流入分布 `BoundaryInflow` | 境界面ごとの Maxwell 分布の係数と倍率(反復の初めに決める) | 0.3 MB |
| セルの係数 `CellParams` | Shakhov の係数(u, A, B, q, θ, coef)、V/τ、V/Δt + V/τ | 6.5 MB |
| モーメント | double、1 セル 15 個(ρ, u, T, p, σ, q)とシフト u0(3 個) | 19 MB |
| 作業領域(速度チャンク) | 制限付き勾配 3 成分 + 残差・増分 1 成分、[セル][チャンク内の位置] | チャンク 2,304 点で 4.98 GB |

- **内部の番号とブロック:** `cell_ordering = "rcb"`(既定)は、セル中心の座標の再帰二分割(RCB: 境界ボックスの最も長い軸で、セル数がブロック数に比例するように分ける)で P 個のコンパクトなブロックに分け、ブロックの中を逆 Cuthill–McKee で並べた番号を内部で使う(ブロックは内部の番号の連続区間)。`"rcm"` は全体を RCM で並べて連続区間で分ける(大きな領域ではブロックが RCM の数段分の薄い層になり、管で不安定になった。§4)。境界面は節点の並びで元の面と対応づける。出力はすべて元の番号に戻す。
- **速度点の保存順(鏡映の組):** 対称面で使う軸の鏡映で移り合う点(軌道。大きさ 2^軸数、1〜8)を連続に並べる。保存位置 p の鏡映は p ^ axis_xor[軸]。速度チャンクの幅とカーネルのタイル(256・128 点)は軌道の大きさの倍数なので、鏡映した点は常に同じチャンク・同じタイルに入る(対称面の流入値に鏡映点の制限付き勾配を使える)。対称面がなければ格子の順そのまま。
- **チャンク幅:** 既定は空き VRAM から自動(f などを確保した後の空きから 1 GB を残し(WDDM の空き容量の報告が当てにならないため)、1 速度点あたり N_cells × (4 × 4 B + 8/256 B) で割って 256 の倍数に切り下げ)。管で 2,304 点(8 チャンク)。

## 3. 1 回の CIS 反復の手順

`prepare()`(f^ℓ について):
1. **モーメント**(GPU、1 ブロック = 1 セル): 前回の u をシフト u0 として、c = ξ − u0 の 13 個の和(f, f c, f c c, f |c|² c)をスレッドごとに FP32 の Kahan の補正付きで足し、ブロック内は FP64 の木構造で足す。シフトのまわりの和から ρ, u, T, p, σ, q を作る(u0 ≈ u なので桁落ちが小さい)。
2. **閉じた領域**(圧力境界がない)なら全質量を規定値(初期化直後の値)に規格化する: f とモーメントを s = M0/M 倍。
3. **収束の指標**(ホスト): 式 (59) の ε を前の反復のモーメントと比べる(§10)。
4. **セルの係数**(GPU): Shakhov の係数、V/τ(τ = μ(T)/p、μ = μ0 T^ω)、対角の定数部分。
5. **圧力境界の W_b**(ホスト、FP64): セルの (p, u, T) を最小二乗勾配(境界の値は前回の境界面の分布のモーメント、仮定 A7)と Venkatakrishnan リミッタ(`physics/limiter.hpp`、ε² = (Kh)³)で境界面へ再構成し、付録 A.2 の W_b を作る(入口: (p_in, u_ib + Δu n, T_in)、出口: (p_out, u_ib + Δu n, T_ib)、Δu = (p_ib − p_b)/(ρ_ib c_s)、c_s = √(γ T_ib))。再構成した p・T が正でなければセルの値を使う。
6. **境界の集計**(GPU、1 ブロック = 1 境界面、128 スレッドで全速度点を順に): 流出側の速度点は隣接セルの制限付き勾配をその場で計算して再構成値を作り、流入側は流入分布(拡散壁は単位密度の値、対称面は同じタイルの鏡映点の再構成値を共有メモリから)。面ごとに 20 個の和(流出・流入それぞれの Σϖ(ξ·n)ψf と Σϖψf、ψ = (1, ξ, |ξ|²/2))を、スレッドごとに FP32 の Kahan の補正付きで、ブロック内は FP64 で足して出す。
7. **拡散壁の ρ_Γ**(ホスト): ρ_Γ = −j⁺/j⁻⁽¹⁾(付録 A.1、j_Γ = 0。j⁺・j⁻⁽¹⁾ は手順 6 の離散和なので、壁の正味の質量流束は離散的に 0)。F⁺・F⁻・境界面の分布のモーメント・パッチの質量流量もここで作る。

`sweep()`(速度チャンク [k0, k0+K) ごとに。チャンクどうしは独立):
1. **勾配 + リミッタ**(1 スレッド = (セル, 速度点))→ 作業領域 G
2. **定常残差**(同上)→ 作業領域 R。セルごとの Σ R² も(ブロック内の木構造 → セルごとに足す)
3. **LU-SGS の前進**(1 スレッド = (空間ブロック, 速度点)。ブロック内のセルを順に)→ R を Δf* に置き換える
4. **LU-SGS の後退**(同上)→ Δf に置き換え、同時に f += Δf

境界の流入分布(壁の ρ_Γ、圧力境界の W_b、対称面の鏡映)と Shakhov の目標分布は手順 1〜7 で固定する(遅れ評価)。

## 4. 離散式

面 e のセル i から見た外向き面積ベクトルを S_out、a = ξ_k·S_out とする。

- 定常残差: R_{i,k} = Σ_e a f_{e,k} − (V_i/τ_i)(f^S_{i,k} − f_{i,k})
  - 面値 f_e: a ≥ 0 ならセル i の制限付き線形再構成 f_i + φ∇f_i·(x_f − x_i)、a < 0 なら隣接セル j から f_j + φ∇f_j·(x_f − x_j)。境界面の a < 0 は §7 の流入値
  - 並進周期の面は和から除く
- LU-SGS(ブロック・ヤコビ。1 次風上の陰的演算子):
  - D = (V/Δt + V/τ) + s Σ_e a⁺ + β Σ_{j∉b} |a⁻_ij|(境界面の流出も含む。並進周期は除く。最後の項はブロック外の隣接セルとの結合を落とした分の対角補償、β = `interface_damping`、既定 0.5)
  - 前進: Δf*_i = (−R_i − Σ_{j<i, j∈b} a⁻_ij Δf*_j) / D_i
  - 後退: Δf_i = Δf*_i − (Σ_{j>i, j∈b} a⁻_ij Δf_j) / D_i、f_i += Δf_i
  - ブロック外の隣接セル・境界の流入値・対称面の鏡映は増分 0(反復の初めの値で固定)
- 擬似時間刻み(仮定 A2、`pseudo_cfl`・`pseudo_time`):
  - `pseudo_cfl = 0`(既定): Δt = ∞(V/Δt = 0、s = 1)
  - `pseudo_time = "global"`: Δt_i = CFL V_i/(ξ_max Σ_f |S_f|)(セルごと、速度によらない。ξ_max = max |ξ|)
  - `pseudo_time = "velocity"`: V/Δt_{i,k} = Σ_e a⁺/CFL(速度点ごと)→ s = 1 + 1/CFL

**安定性について(実装して分かったこと):** 2 次精度の残差と 1 次の陰的演算子の組み合わせ(defect correction)は、1 次元の Fourier 解析で、点ヤコビ(1 ブロック = 1 セル)のとき |1 − J₂/D| > 1 になる波数がある(Fromm 型の面値で θ = π/2 に 1.58)。実際に、平板の 8 セルを 8 ブロックに分けると Δt = ∞ で発散し、`pseudo_time = "velocity"` の CFL = 10, 3 でも発散、CFL = 1 で停滞した。2 セル以上のブロックなら収束する。管(135,104 セル)では、全体の RCM を 64 の連続区間に分けると(1 ブロック 2,111 セル)、上流槽・下流槽でブロックが RCM の 1〜3 段の薄い層になり、出口付近で発散した(P = 8 なら安定)。そこでブロックを RCB のコンパクトな塊(1 ブロックの厚さが 10 セル程度)にした。ブロックが小さくなりすぎないように、`sweep_blocks = 0`(既定)はセル数/2048 を 1〜64 に収めた値にする(管は 64、平板は 1)。RCB のブロックでも、管を横切る分割面(軸方向の速い流れがブロック境界を横切るところ)で残差が 1 反復 1% ほどで増え続けたので、ブロック外の結合 |a⁻| の β 倍を対角に足すようにした(β = 0.5 で単調に減る。収束した解は変わらない)。

## 5. 勾配とリミッタ

- 最小二乗(重みなし。`lsq_weight_power` で |r|^{−p} の重み)。係数 c_k = G⁻¹ r_k は `mesh/fv_geometry.hpp` の `LsqGradient`(境界面は面中心 r = x_f − x_i)を無次元にして使う。
- 境界面の値(仮定 A3 の補足):

| 境界 | 流入側の速度点 | 流出側の速度点 |
|---|---|---|
| 拡散壁・圧力・真空 | 流入分布(反復の初めの値) | f_i(勾配 0 の外挿) |
| 対称面 | (f_i(ξ) + f_i(ξ'))/2 | 同左 |
| 並進周期 | f_i(寄与 0) | 同左 |

  対称面の値は、鏡映した仮想セル(面の向こう、距離 2d)の値 f_i(ξ') を使う最小二乗の行と同じ傾きになる(厳密に対称な解では面の値そのもの)。最初の実装の「流入側は f_i(ξ')(面中心に置く)」は、鏡映の反対称成分を 2 倍に増幅して、1 セル厚の平板で発散した。

- Venkatakrishnan リミッタ(`physics/limiter.hpp`): 面ごとに Δ2 = ∇f_i·(x_f − x_i)、f_max・f_min は自分と隣接セル(境界は上の表の値)の最大・最小、φ_i = min_f φ_f(並進周期の面は除く)、勾配に φ を掛けて作業領域に置く。
  - `limiter_eps = "relative"`(既定)、K = 3(既定): ε² = K³ V · max(|f_max|, |f_min|)²(速度点ごとの桁の違いをそろえる。相対的な許容幅は (Kh)^{3/2}。管の h = 0.05〜0.5 では 6%〜180% なので、真空との境のような強い不連続でだけ働く)
  - `limiter_eps = "absolute"`: ε² = (K h)³ = K³ V(無次元。設計の初版の既定)
  - `limiter = "none"`: 勾配をそのまま使う
  - 無次元の f の大きさ(管で最大 0.06 程度)に対して、absolute・K = 5 の ε は h = 0.05〜0.5 で 0.1〜5 なので、リミッタはほとんど働かない。この設定では管(δ = 1、Δt = ∞)が出口付近と管出口の角(真空に近い膨張域)で発散した(反復 25〜64 回目に T < 0)。relative・K = 1 と RCB のブロックで安定になり、さらにブロック境界の対角補償(§4)を入れると relative・K = 3 と absolute・K = 5 でも安定だった。粗い管で K = 1 の出口の流量がリミッタなしと 0.4〜2% 違った(K = 3 は 0.15% 以内)ので、強い不連続でだけ働く relative・K = 3 を既定にした。ただし四面体の管(`tube_tet`)では K = 3 が下流槽の真空に近い大きなセルで発散し、K を下げる必要があった(`phase2_report.md` §3.5。正値性のリミッタが今後の課題)。影響は `phase2_report.md` のパラメータの表。

## 6. 並列化(GPU)

| カーネル | スレッドの割り当て | 起動の分け方(WDDM の TDR、1 回 100 ms 未満) |
|---|---|---|
| `k_moments` | 1 ブロック(256)= 1 セル、スレッドは速度点を分担 | `launch_cells`(既定 16,384)セルずつ |
| `k_cell_params` | 1 スレッド = 1 セル | 1 回 |
| `k_boundary_sums` | 1 ブロック(128)= 1 境界面、タイル 128 点ずつ全速度点 | 2,048 面ずつ |
| `k_gradient` | 1 ブロック(256)= 1 セル × 256 点(grid = (セル, タイル))| `launch_cells` セルずつ |
| `k_residual` | 同上。ブロック内で Σ R² を木構造で足し、セル × タイルの部分和に書く | 同上 |
| `k_sweep_forward` / `k_sweep_backward` | 1 ブロック(128)= 1 空間ブロック × 128 点。各スレッドがブロック内のセルを順に処理 | 各ブロックの `sweep_cells_per_launch`(既定 4,096)セルずつ。前後の依存は同じストリームの起動順で保つ |
| `k_gsis_correction` | 1 ブロック(256)= 1 セル。最小値はブロック内の木構造 | `launch_cells` セルずつ |
| `k_internal_face_mass_flux`(フェーズ 5c) | 1 ブロック(128)= 1 内部面、スレッドは速度点を分担。面の値は残差と同じ風上の制限付き再構成で、勾配はその場で計算(`internal_face_flux_term`)。断面の質量流量の集計(`KineticSolver::section_mass_flow`、`docs/design_gsis.md` §6a)だけに使う | 2,048 面ずつ |

- warp は同じセルの連続する速度点を受け持つので、f・作業領域の読み書きは 128 B 単位で連続し、メッシュの量(CSR の要素など)は warp 内で同じ番地(ブロードキャスト)になる。
- 総和はすべて決まった順序(スレッドごとの順 + 共有メモリの木構造)で、atomic を使わない。同じ入力で 2 回計算するとビット単位で同じ。起動の分け方(セル範囲・スイープの範囲・チャンク幅)を変えても結果はビット単位で同じ(テストで確認)。
- 処理ごとの時間は CUDA イベントで測る(`KineticIterationInfo::timings`)。

## 7. 境界条件(運動論側)

| 種類 | 流入分布 f^bc(a < 0 の速度点) | 備考 |
|---|---|---|
| 拡散壁(`diffuse_wall`、壁速度あり) | ρ_Γ,b f^eq(1, u_w, T_w; ξ)、ρ_Γ,b = −j⁺_b / j⁻⁽¹⁾_b | j⁺ は流出側の再構成値の離散和、j⁻⁽¹⁾ は単位密度の壁 Maxwell 分布の離散和。反復の初めに決める(遅れ評価)。壁速度は面に接する向きでなければエラー。`wall_relaxation` で ρ_Γ を緩和できる(F⁻ は緩和しない値) |
| 圧力入口・出口 | f^eq(W_b)(付録 A.2、§3 の手順 5) | `pressure_outlet` で p = 0 なら真空と同じ扱い |
| 真空 | 0 | |
| 対称面 | 鏡映した速度点の流出側の再構成値 f_i(ξ') + φ∇f_i(ξ')·(x_f − x_i) | 法線が速度格子の軸に揃った面だけ(`config/case_mesh_check`)。鏡映する軸の点数は偶数 |
| 並進周期(`periodic_slab`) | なし(面を流束の和から除く) | 1 セル厚の方向の対面だけ |

- 初期化の直後の ρ_Γ は、隣接セルが平衡分布とみなした値 ρ_i √(T_i/T_w) を仮に使い、最初の境界の集計で決め直す。
- **閉じた領域**(圧力境界がない)は、反復ごとに全質量を初期化直後の値に規格化する(定常方程式から全質量が決まらないため。spec §3.8)。
- **収束の速さ(実装して分かったこと):** 対称面の鏡映の流入は前の反復の値で固定しているので、1 セル厚の平板の側面に対称面を使うと、面にほぼ平行な速度点では対角に (|ξ_y| + |ξ_z|)A が入るのに流入側が遅れ、大きな擬似時間刻みと同じ働きになる(熱伝導 Kn = 10 で 2,206 反復。側面を並進周期にすると 20 反復で同じ値に収束)。収束した解は同じ。陰的に扱うには、軌道(鏡映の組)ごとの小さな連立 1 次方程式を warp 内で解く必要がある(未実装)。

## 8. GSIS への出力と補正

- `boundary_fluxes()`: F^{±,0}_b = A_b Σ_{Ξ±} ϖ (ξ·n_b) ψ f_b(流出側は再構成値、流入側は境界条件の値。拡散壁は緩和しない ρ_Γ を掛けるので F⁺_ρ + F⁻_ρ = 0)、境界面の分布の [ρ, u, T]。境界面の並びは元のメッシュの境界面の番号(面番号 − n_internal_faces)。
- `apply_gsis_correction(W_half, W_new)`: 各セルで f ← f − f^eq(W_half) + f^eq(W_new)(FP32 なら FP32 で計算)。その後 min_k f < −10⁻⁸ ρ_new/T_new^{3/2} のセルは全速度点を f^eq(W_new) に置き換え、置き換えたセル数を返す。シフト u0 も W_new の u にする。

## 9. CPU 参照実装

`backend = "cpu"`(`kinetic_backend_cpu.cpp`)。同じ前処理と `kinetic_kernels.hpp` の関数を使い、セル・(ブロック, 速度点)・境界面で OpenMP 並列にする(書き込み先が重ならないので結果はスレッド数によらない)。モーメントと境界の集計は FP64 でそのまま足す。GPU 版との差は FP32 で相対 2×10⁻⁵ 以内、FP64 で 10⁻¹¹ 以内(全種類の境界条件を含む歪んだ箱のメッシュで 6 反復。`tests/kinetic/test_kinetic_gpu.cpp`)。

## 10. 収束判定(CIS 単独、`cis-run`)

- 式 (59): ε = max_{Q∈{ρ,u,T}} [Σ_i |Q^ℓ_i − Q^{ℓ−1}_i|² V_i / Σ_i |Q^{ℓ−1}_i|² V_i]^{1/2} < tol(既定 `[gsis].tolerance`)
- u の分母には下限 floor² ΣV を設ける(`convergence_u_floor`、既定 0.01 √(RT0))。静止に近い流れ(平板の熱伝導)では u が FP32 の丸めの雑音(10⁻⁸ 程度)だけになり、0/0 で ε が下がらないため。管(rms |u| ≈ 0.1)には影響しない。
- FP32 の丸めによる ε の下限: ε_ρ・ε_T は 10⁻⁹ 程度、ε_u は rms|Δu| が 10⁻⁸〜10⁻⁷ 程度(平板)。tol はこれより大きくする。
- ε は 1 反復の変化なので、CIS の収束が遅いと定常の手前で止まる(管 δ = 1 の ε < 10⁻⁵ で入口と出口の流量が 4.7% 違う。δ = 10 は上流槽の遅い振動のため ε < 10⁻⁶ でも 4% 違う)。`cis-run` の結果を使うときは `summary.json` の入口と出口の流量の一致も確かめる(`phase2_report.md` §3.3・§3.4)。

## 14. フェーズ 5a の追加(CIS の強化と保存的な離散平衡)

背景(`docs/phase4_report.md` §3 の 7、`docs/phase5_report.md`): GSIS の速い収束の理論は、運動論の段が輸送方程式を
解き切る「源反復」に近いことを前提にしている。従来の CIS(LU-SGS 1 往復、ブロックの中は全速度点で共通の RCM の順、
ブロック間はブロック・ヤコビ)は、(a) 速度の向きとセルの順序がそろわない速度点で風上の依存を 1 回で解き切れず、
(b) 2 次の欠損補正(1 次の左辺と 2 次の右辺)の誤差を 1 回で半分ほどしか減らさず、(c) 拡散壁の反射を 1 反復に 1 回
しか進めない。管の CIS 単独が論文の 4 倍の反復を要し(δ=1 で 755 ↔ 189)、粗い管の 2 倍の反復になる(メッシュに
よる)のはこのため。平均自由行程より短い波長の誤差が CIS で減らないと、PBC 段(NSF の合成方程式)がそれを kλ 倍に
増幅して GSIS が発散する。

### 14.1 速度点の向きごとのスイープの順序(`sweep_order`)

- 向きの組 d_g(符号は区別しない): `"octant"` は体対角 (1, ±1, ±1)/√3 の 4 方向、`"dir13"` は軸 3・面対角 6・体対角 4 の
  13 方向。速度点 ξ は |ξ·d_g| が最大の向き g を使う(`sweep_direction_of`)
- 各ブロックの中のセルを x·d_g の小さい順に並べた順序 `sweep_order[g]` と、その位置 `sweep_pos[g]` を前処理で作る
  (`kinetic_setup.cpp`。ブロックの区間は変えない)。LU-SGS の前進スイープはこの順、後退は逆順にたどり、
  「j < i」(L に入る隣接セル)を位置で判定する
- ξ·d_g > 0 の速度点の風上のセルはほぼ x·d_g の小さい側にあるので前進スイープで、ξ·d_g < 0 の速度点は後退スイープで
  風上の依存をほぼ厳密に解く(直交格子なら厳密。もう一方のスイープは対角だけの働き)
- 鏡映を使わない(対称面がない)ときは、速度点の保存順を向きごとにまとめる(同じ warp が同じセルの順序をたどるので、
  メッシュの量の読み込みがブロードキャストのまま)。対称面があると鏡映の組が別の向きにまたがるので、warp の中で
  順序が分かれる(結果は正しいが遅い)
- メモリ: 向き 1 つあたり セル数 × 8 バイト(管の octant で 4.3 MB)

### 14.2 内部反復(`inner_sweeps`・`inner_wall_update`)

- 1 回の CIS 反復(`KineticSolver::sweep`)の中で、`prepare` で作った Shakhov の目標分布・圧力境界の W_b を固定したまま、
  LU-SGS(勾配・残差・前進・後退。全チャンク)を `inner_sweeps` 回くり返す。2 次の欠損補正の反復が進み、
  ブロック・ヤコビの情報も 1 回にブロック `inner_sweeps` 個分進む。残差の記録は 1 回目(f^ℓ の残差)
- `inner_wall_update = true` なら、内部反復の間に境界の集計(`k_boundary_sums`)から拡散壁の流入密度
  ρ_Γ = −j⁺/j⁻⁽¹⁾ を作り直す(壁での反射も内部反復で進む。1 回 23 ms)。F^±・境界面のモーメント・流量の記録は
  `prepare` の値のまま
- 時間は 1 反復あたりほぼ `inner_sweeps` 倍(管で 1 回 0.6 s)
- `block_passes = K`(ブロック間の結合の反復): 残差の計算の後、勾配の作業領域を使い回して残差 R(gx)と前の回の Δf(gy)を置き、
  前進・後退スイープを K 回くり返す。2 回目以降は D Δf_i = −R_i − Σ_{ブロック外の風上} a⁻ Δf_prev,j − (ブロックの中の L・U) とし
  (対角補償 β は使わない)、f は最後の回だけ更新する。1 次の陰的演算子のブロック・ヤコビ反復で、管の RCB のブロック(管を軸方向と
  y = 0 で切る)を横切る壁から壁への飛行も 1 回の CIS で解く。1 回 0.26 s(前進・後退)と作業領域の写し

### 14.2a 管での効果と既定の選び方(`docs/phase5_report.md` §2)

本番の管 δ=1 の CIS 単独(ε < 1e−5): 従来 755 回 → octant 594 回 → octant + 内部反復 4 回 + 壁の更新 + ブロック間の反復 2 回 +
離散平衡 145 回(1 反復 3.68 s)。GSIS では、平板の Kn = 10 で内部反復 2 回では発散し 4 回で収束した(2 次の欠損補正の誤差が
1 回で約半分しか減らず、PBC 段が平均自由行程より短い波長の誤差を kλ 倍に増幅するため)。

**フェーズ 5b でコードの既定値をこの設定にした**(ユーザーの判断 2026-10-17): `sweep_order = "octant"`、`inner_sweeps = 4`、
`inner_wall_update = true`、`block_passes = 2`、`equilibrium = "discrete"`(と GSIS の負値の規則 `gsis_negative_check = "blend"`)。
従来の値はケースで指定すれば使える。既定値の変更で数値が変わったテストは 3 件で、どれも従来の設定や連続の平衡分布を前提に
期待値を作っていたため(`docs/phase5b_d1000_report.md` §1)。

δ=1000 の真空の出口の手前の冷たい噴流(T ≈ 0.02〜0.1、Δξ = 2/3 では表せない)では、K = 3 のリミッタで CIS 単独も 78 回目に
負の温度になる。K = 1(K = 0.3 も)なら 400 回まで安定(ケースで `limiter_k = 1`)。

### 14.3 保存的な離散平衡分布(`equilibrium = "discrete"`、`kinetic/discrete_equilibrium.hpp`)

- 速度格子の上の離散モーメントが (ρ, ρu, ρE) に一致する Maxwell 分布 M_d = exp(β0 + β·c + β4|c|²/2)(c = ξ − u)の
  係数 β をニュートン法で決める(Mieussens の離散速度模型の平衡。J = Σϖψ0ψ0ᵀM_d、1 歩の大きさは温度が 2 倍・半分、
  密度の対数が 1 までに抑える)。M_d は係数を変えた Maxwell 分布 A exp(−B|ξ − u'|²) なので、カーネルの評価は従来のまま
- Shakhov の目標分布は f^S = M_d [1 + P + γ0 + γ·c + γ4|c|²/2]。P は連続の目標分布の多項式(中心はセルの u、温度は T)、
  γ は P の離散モーメントを打ち消す補正(J γ = −Σϖψ0 M_d P)。これで Σψ f^S = Σψ f(衝突項が速度格子の上で保存的)
- 使う場所: Shakhov の目標分布(`update_cell_params`。GPU は 1 ブロック = 1 セルの `k_cell_params_deq`)、
  GSIS の補正(式 (14))の M(W^{n+1/2})・M(W^{n+1}) と負値の置換、初期化、境界の流入の Maxwell 分布
  (圧力境界・拡散壁。ホストで FP64 のニュートン法をして、同じ形の (ρ', u', T') にして渡す)
- 速度格子で十分に解像される分布(各軸で中点則の誤差 exp(−2π²T/Δξ²) と範囲の外の裾 exp(−(端までの距離)²/2T) が
  exp(−27) 未満)は補正しない(連続のものと丸め誤差の範囲で同じ)。Δξ = 2/3 では T < 0.6、または速度格子の端に近い
  速い流れのセルだけを補正する
- ニュートン法の打ち切り: モーメントの相対誤差 < 1e−6(FP32)・1e−11(FP64)か、1e−4 未満で減らなくなったとき(FP32 の
  丸めの水準)。20 回で収束しないか J が特異なら、連続の Maxwell 分布にして数を記録する(`KineticIterationInfo::deq_failed`、
  警告を出す)
- 冷たい流れでは連続の Maxwell 分布の離散モーメントがずれる(Δξ = 2/3、T = 0.1 で温度 0.88 倍・密度 1.04 倍)ので、
  衝突のたびに温度が下がり密度が増えて CIS が壊れた(管 δ = 1000 の真空の出口の手前、`docs/phase4_report.md` §5.3)

## 15. フェーズ 5b の追加(冷たいセルの扱い。`docs/phase5b_d1000_report.md`)

管 δ=1000 の真空の出口の近くでは、運動論の解の温度が 0.01〜0.03 まで下がり、速度格子(Δξ = 2/3)の 1〜2 点に分布が集まる。
負でない分布が速度格子の上で持てる温度には下限があり、各軸で隣り合う 2 点に分けたときの分散の平均
T_min(u) = (1/3) Σ_a (u_a − ξ_{k_a})(ξ_{k_a+1} − u_a)(ξ_{k_a} ≤ u_a ≤ ξ_{k_a+1}。Δξ = 2/3 では 0〜0.11。u_y = u_z = 0 の軸の上では
0.074 以上)。これより冷たい状態(PBC 段が作る W^{n+1} など)には離散平衡が存在しない。

| `[kinetic]` | 既定 | 内容 |
|---|---|---|
| `deq_fallback` | "collisionless" | 離散平衡のニュートン法が収束しないセル(モーメントが表せる限界に近い・超える)の扱い。"collisionless": 目標分布の衝突項を 0 にする(`coll = 0`、目標分布 = f。保存的で、負の値を作らない)。GSIS の補正では W^{n+1/2} か W^{n+1} の離散平衡が作れないセルを補正しない(f をそのままにして、置換の数に数える。印は `kCorrectionSkipped`)。"continuous": フェーズ 5a の扱い(連続の Maxwell 分布。離散モーメントが合わず、冷たいセルでは衝突のたびに壊れる) |
| `cold_bgk_temperature` | 0(使わない) | この温度より冷たいセルの目標分布を BGK(Shakhov の多項式なし、局所的に Pr = 1)にする。速度格子で解像できない冷たいセルでは、Shakhov の多項式と離散保存の補正 γ(J がほぼ特異)が隣の速度点で大きくなり、目標分布が負になって CIS が負の温度になる |
| `pressure_boundary_reconstruction` | "limited" | 圧力境界の流入分布の W_{i,b}: "limited"(論文どおり)/ "cell"(セルの値)。δ=1000 の粗い管で "cell" は悪化した(試験用に残す) |

`deq_fallback` は δ ≤ 100 の管と平板ではニュートン法の失敗がない(フェーズ 5a の記録)ので、結果を変えない。

## 16. 四面体での正値性リミッタの検証(フェーズ8 S1)

`[kinetic].positivity_limiter = true` は、Venkatakrishnan の制限の後に、全ての非周期面への増分から
`phi <= f_i / (-min(grad f dot r_f))` を課す。`limiter = "none"` のときも正値性は独立に適用する。
`f_i <= 0` のセルは勾配を0にする(負のセル値自体を修正するものではない)。

旧実装は `limiter = "none"` の早期returnで正値性まで無効にしていた。S1でこの組合せを修正し、歪んだ四面体の内部面・境界面の再構成をFP32/FP64で調べるテストと、四面体のGPU/CPU一致・決定性のテストを追加した。

この制限が保証するのは、正のセル値から面中心に再構成する値の非負性(丸め誤差の範囲)である。
LU-SGSの更新やShakhovの目標分布の非負性は別の問題なので、名前だけから反復全体の正値性を仮定しない。

全体の既定値falseは維持する。四面体での診断設定、管δ=1・10の計算結果、六面体との比較は
`docs/phase8_s1_report.md` と `cases/general/tet_tube/` を参照する。


### 固定した分布に対する境界更新(S1の検証用)

`boundary_iterations` は、セルのfを変えずに、圧力流入分布の更新・半空間の集計・壁密度と境界モーメントの更新を反復する。
壁と圧力境界などが同一セルに接する場合、最小二乗の再構成に使う境界値が他の境界の流入分布に依存するため、1回の遅れ評価と固定点は一致しない場合がある。
既定の1回では従来の評価順を維持する。一般の形状での有効性と推奨値はS1の計算結果で判断し、反復数を増やせば必ず収束するとは仮定しない。
CPUの固定fでの分割反復との一致と誤差の低下、GPU/CPUの一致を単体テストで確認する。
