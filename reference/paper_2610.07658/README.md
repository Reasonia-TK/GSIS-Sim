## Fig.3 のデジタイズ

### 対象と系列

Fig.3 は管の中心線上の分布(入口 X=0 から出口 X=10)。図の説明文は「線が GSIS-PBC、黒丸が δ=100 の DSMC、その他の記号が CIS」。δ=1000 は描かれていない。

| 系列名(ファイル名の `<系列>`) | 原図の表現 | 点数(圧力 / 速度) |
|---|---|---|
| `gsis_delta1` | 黒の実線 | 691 / 1072 |
| `gsis_delta10` | 黒の破線 | 500 / 685 |
| `gsis_delta100` | 黒の一点鎖線(長・短・短) | 306 / 406 |
| `cis_delta1` | 赤の四角 □ | 12 / 12 |
| `cis_delta10` | 緑の下向き三角 ▽ | 12 / 12 |
| `cis_delta100` | 青の菱形 ◇ | 12 / 12 |
| `dsmc_delta100` | 黒の丸 ○ | 23 / 20 |

列の定義(すべて無次元):

| 列 | 意味 |
|---|---|
| `X` | $X=x/L_{ref}$($L_{ref}$ = 管半径)。管の入口が X=0、出口が X=10 |
| `P` | $P=p/p_{in}$(入口圧力で割った圧力) |
| `Ux` | $u_x/\sqrt{2RT_0}$(軸方向速度。$T_0=273.15$ K) |

- 線の系列は、線が見えている所だけの点列(X の小さい順)。点の間隔はおおむね画素 1 列ぶん(X で約 0.01)。傾きの急な所は 1 行ごとに 1 点なので X は等間隔でない。破線のすき間・記号に隠れた所・線どうしが重なる所には点がない(下の「取れなかった区間」)。比較では X で補間して使う。
- 記号の系列は、記号 1 個につき 1 行で、記号の中心(▽ は重心)の座標。

### 方法

1. **軸の較正**: 枠の内側の目盛り線(主目盛り+副目盛り、x 軸 21〜22 本、y 軸 19〜20 本)の位置を、黒の濃さで重み付けして小数画素で求め、値(主目盛りは図の数字、副目盛りは X が 0.5、値が 0.05 刻み)との 1 次式を最小二乗で当てた。

   | 図 | X 1 単位 | 値 1 単位 | 1 px の大きさ | 目盛りの残差(最大) |
   |---|---|---|---|---|
   | 圧力 | 98.75 px | 1008.7 px | X 0.0101、P 0.00099 | 0.45 px(x)、0.49 px(y) |
   | 速度 | 98.40 px | 985.6 px | X 0.0102、Ux 0.00101 | 0.45 px(x)、0.52 px(y) |

   残差は目盛りが整数画素に丸めて描かれていることによる(±0.5 px)。圧力図では枠の上端が P = 1.0006 に当たり、図の「1」の位置と合う。
2. **記号(CIS・DSMC)**: 凡例の記号をそのまま型にして、色の重み(赤・緑・青、黒丸は黒の濃さ)と相関をとり、極大を記号の位置とした。ほかの色や黒線に隠れた画素は評価から外したので、X=0 で 4 種の記号が重なっていても中心が求まる。黒丸は円周の 16 区画のうち隠れていない区画の 80% 以上に黒があることも条件にした。検出数は目で数えた数と一致した(各 12 個、DSMC は 23 / 20 個)。
   - 記号の基準点は型の輪郭の重心。▽ の重心はバウンディングボックス中心より約 3.4 px 上にある。凡例の記号は等間隔の行に置かれるので、点対称な □・◇・○ の中心から ▽ の行の位置を求めると、圧力図 980.34 px・速度図 394.05 px で、▽ の重心(980.13 / 394.13 px)と 0.2 px 以内で一致した(バウンディングボックス中心は 983.5 / 397.5 px)。よって作図ソフトは ▽ を重心で置いている。
3. **線(GSIS-PBC)**: 3 本とも黒なので、記号の色の画素・黒丸の輪・凡例・枠を除いた黒画素を使い、傾きが緩い所は 1 列ごとの縦の連続区間、急な所(画面上で 45° 超)は 1 行ごとの横の連続区間に分け、黒の濃さで重み付けした中心を線の位置とした。どの線の画素かは、拡大画像から読んだ案内点(`digitize_fig3.py` の `guides`)を出発点にして判定し、抽出した点の局所回帰で案内曲線を更新しながら 4 回繰り返した。次の点は捨てた。
   - 2 本の線の幅が同じ列(行)で重なる所(交差部)
   - 区間が線 1 本の幅より長い所(線どうし、線と記号がくっついた塊)
   - 記号・黒丸の輪に接していて、しかも線 1 本の幅より短い所(一部が隠れている)
   - 線が傾いている所(画面上の傾き 0.4 超)では、破線・点線の 1 片の両端の 1〜3 列(行)(端の切り口のせいで中心がずれる。短い点は中央の 1 つだけ残す)
   - 近くの点の局所回帰から 1.5 px 以上離れた点
4. **確認**: `check/` の図は、書き出した CSV を読み戻してデータ座標で描き、較正式で位置を合わせた原画像に重ねたもの。緑の細線は較正式で描いた X = 0〜10(1 刻み)と値 0〜1(0.1 刻み)の格子で、原図の目盛りと重なることで較正を確かめられる。全体図と拡大図(入口・交差部・中央・出口)を目で見て、線と記号からのずれ、別の線への誤った割り当て、記号の見落としがないことを確かめた。

### 読み取り誤差の目安

| 項目 | 目安 |
|---|---|
| 1 px の大きさ | X 0.0101(速度図 0.0102)、P 0.00099、Ux 0.00101 |
| 軸の較正 | 目盛りの残差 ≤ 0.52 px。当てた 1 次式の誤差は 0.2 px 程度 |
| 線の点のばらつき | 局所回帰からの残差 RMS 0.20〜0.31 px、最大 1.3 px(線に細かい縞模様があるため) |
| 線の位置 | 線の太さは約 5 px。中心の推定は ±1 px 程度と見る → P・Ux で ±0.001、X で ±0.01 |
| 記号の位置 | ±0.5 px。▽ の基準点(重心)の不確かさは 0.2〜0.3 px |
| 傾きの急な所 | X の誤差 0.01 が値の誤差になる。例: 速度図 δ=1 の出口付近は dUx/dX ≈ 0.4 なので Ux で ±0.004 |

### 注意点

- 線の両端: 線は X=0 から X=10 まで描かれているが、端の値は記号に隠れているか、線の端の切り口で中心がずれるため、点列は X≈0.003〜0.15 から X≈9.97〜10.00 まで。端の値が必要なら近くの点から外挿する。
- 速度図の δ=100 の線は X=0 の黒丸の中に入らず、黒丸の上端(Ux≈0.287)から始まる。抽出した最初の点は X=0.029、Ux=0.291。DSMC の X=0 の値は 0.276 で、入口では GSIS-PBC と DSMC に約 0.01 の差がある。記号は中抜きで、ほかの場所では記号の内側に線が見えているので、隠れたのではなく線がそこから始まっていると読める。
- 圧力図の X<0.15 では δ=1 と δ=100 の線がほぼ同じ点(P≈0.92)から出て重なるので、どちらの値も取っていない。
- δ=100 の GSIS-PBC の線は、DSMC の黒丸の中心をそのまま通るわけではない。黒丸の両側 X±0.06 以内に線の点がある所で比べると、DSMC − GSIS-PBC は圧力で −0.005〜+0.003、速度で −0.004〜+0.006 だった。速度図の出口付近(X≈9.3、9.64)では −0.008、−0.017 と差が大きく、線が黒丸の左上を通っている。どれも拡大図で、抽出の誤りではなく図に描かれた差であることを確かめた。
- 原図は作図ソフト(Tecplot と思われる)が描いた折れ線で、元のデータ点の間隔はわからない。デジタイズ値はその折れ線をなぞったもの。
- DSMC は SPARTA の 2 次元軸対称計算(VHS)。CIS と GSIS-PBC は同じ 3 次元格子(135,000 セル)・速度格子で解いたもの(§4.1)。
