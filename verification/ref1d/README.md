# ref1d — 平行平板間の 1 次元参照ソルバー(Shakhov モデル)

3 次元ソルバー(GSIS-PBC / CIS、`docs/spec.md` §5.2)を平行平板間の問題で検証するための「正解」を作る 1 次元ソルバーと、その結果。
熱伝導(Fourier 流)とクエット流を Kn = 0.01〜10 で解き、熱流束 $q_x$ とせん断応力 $P_{xy}$ を相対 3e-8 以下(壁での熱流束は 2e-6 以下)まで格子収束させた。自由分子解、NSF + すべり・温度跳躍の解、文献の数値表(線形化 BGK/S モデル、非線形 Shakhov)と照合済み(§5)。

- ソルバー: `src/ref1d/`(numba で並列化した Python)
- 実行スクリプト: `scripts/`
- 結果: `results/`(分布の CSV、要約の CSV、検証・収束の CSV、図)

---

## 1. 問題設定

### 1.1 支配方程式
定常・1 次元(平板の法線方向 $x$)の Shakhov モデル(論文の式 (1)–(3))。

$$
\xi_x \frac{\partial f}{\partial x} = \nu\,(f^S - f),\qquad
f^S = f^M\left[1 + \frac{(1-\Pr)\,\boldsymbol c\cdot\boldsymbol q}{5\,p\,RT}\left(\frac{c^2}{RT} - 5\right)\right],\qquad
f^M = \frac{\rho}{(2\pi RT)^{3/2}}\exp\!\left(-\frac{c^2}{2RT}\right)
$$

- $\boldsymbol c = \boldsymbol\xi - \boldsymbol u$、$\nu = p/\mu$、$\Pr = 2/3$、単原子
- 粘性はべき乗則 $\mu = \mu_0 (T/T_0)^\omega$、$\omega = 0.66$(管ケースの He と同じ)
- $\Pr = 1$ にすると BGK モデルになる(文献との比較にだけ使う)

### 1.2 形状と境界条件
- 2 枚の平板 $x = 0$(左の壁)と $x = L$(右の壁)。$y, z$ 方向には一様(無限平板)。
- 完全拡散反射。壁から気体へ向かう分子(左の壁では $\xi_x > 0$)の分布は $n_w f^M(\boldsymbol\xi;\ \rho=1,\ \boldsymbol u_w,\ T_w)$。
  壁の流入密度 $n_w$ は、**離散速度空間で壁の正味質量流束がゼロ**になるように決める(論文の付録 A.1 と同じ。§3.4)。
- 平板間の平均密度を $\rho_0$ に保つ(全質量の保存。§3.5)。

### 1.3 ケース

| 名前 | 内容 | 左の壁 ($x=0$) | 右の壁 ($x=L$) |
|---|---|---|---|
| `heat_lin` | 熱伝導(線形域) | $T_L/T_0 = 0.95$、静止 | $T_R/T_0 = 1.05$、静止 |
| `heat_nl` | 熱伝導(非線形) | $T_L/T_0 = 0.5$、静止 | $T_R/T_0 = 1.5$、静止 |
| `couette_lin` | クエット流(線形域) | $T_0$、$u_y = -0.1\sqrt{RT_0}$ | $T_0$、$u_y = +0.1\sqrt{RT_0}$ |
| `couette_nl` | クエット流(非線形) | $T_0$、$u_y = -1\sqrt{RT_0}$ | $T_0$、$u_y = +1\sqrt{RT_0}$ |

Kn = 0.01, 0.02, 0.05, 0.1, 0.2, 0.5, 1, 2, 5, 10(`src/ref1d/cases.py` の `CASE_TYPES`, `KN_LIST`)。
クエット流の壁速度 $u_w/\sqrt{RT_0} = 1$($\mathrm{Ma}\approx 0.77$)でも反復は問題なく収束した。

## 2. 無次元化と出力量の定義

### 2.1 基準量

| 量 | 基準 |
|---|---|
| 長さ | 板間隔 $L$ |
| 温度 | $T_0 = (T_L + T_R)/2$(2 枚の壁温の平均) |
| 密度 | $\rho_0$ = 板間の平均密度($\int_0^L \rho\,dx = \rho_0 L$) |
| 圧力・応力 | $p_0 = \rho_0 R T_0$ |
| 速度 | $\sqrt{RT_0}$ |
| 熱流束 | $p_0\sqrt{RT_0}$ |

- $\mathrm{Kn} = \dfrac{\mu(T_0)}{p_0 L}\sqrt{\dfrac{\pi R T_0}{2}}$(論文の式 (8))。希薄度パラメータ $\delta = \dfrac{p_0 L}{\mu(T_0)\sqrt{2RT_0}} = \dfrac{\sqrt\pi}{2\,\mathrm{Kn}}$(論文の $\delta_{rp}$ と同じ形、文献の $\delta$・$2a$ とも同じ)。
- 無次元の衝突頻度は $\hat\nu = \sqrt{\pi/2}\,\hat\rho\,\hat T^{1-\omega}/\mathrm{Kn}$。
- `docs/spec.md` §3.2 の基準量($p_{ref} = p_{in}$ など)は管ケース用。平板の比較では上の基準に換算する(§7)。

### 2.2 出力する量(すべて上の基準で無次元化)

| 量 | 定義 |
|---|---|
| `rho`, `ux`, `uy`, `T` | $\rho = \int f$、$\rho\boldsymbol u = \int\boldsymbol\xi f$、$\frac32\rho RT = \int\frac12 c^2 f$($c^2 = \boldsymbol c\cdot\boldsymbol c$) |
| `p` | $p = \rho R T$(スカラー圧力) |
| `Pxx`, `Pxy`, `Pyy`, `Pzz` | 圧力テンソル $P_{ij} = \int c_i c_j f$($P_{xy}$ がせん断応力、$\sigma_{ij} = P_{ij} - p\delta_{ij}$) |
| `qx`, `qy` | 熱流束 $q_i = \int \frac12 c^2 c_i f$ |
| `Qtot` | $x$ 方向の全エネルギー流束 $\int \xi_x \frac12 \xi^2 f = q_x + u_y P_{xy}$($u_x = 0$、$\xi^2 = \boldsymbol\xi\cdot\boldsymbol\xi$) |
| 壁での値 | 壁の節点($x = 0, L$)で、流入する壁 Maxwell 分布と流出する分布の両方から計算したモーメント |
| 温度跳躍・速度すべり | `T_jump_L` $= T(0) - T_L$、`slip_L` $= u_y(0) - u_{y,L}$(右の壁も同様) |
| 壁の座標系での熱流束 | `qwall_L` $= Q_{tot} - u_{y,L} P_{xy}$(クエット流で壁に伝わる熱。熱伝導では $q_x$ と同じ) |

符号: $q_x$ は $+x$ 向きが正(熱伝導ケースは $T_L < T_R$ なので $q_x < 0$)。クエット流は左の壁が $-u_w$、右の壁が $+u_w$ で動くので $P_{xy} < 0$。
厳密解では $q_x$(熱伝導)、$P_{xy}$、$P_{xx}$、$Q_{tot}$ は $x$ によらず一定で、質量流束はゼロ。

## 3. 数値解法

### 3.1 速度空間: 縮約分布関数(ξy, ξz は解析的に積分)
$f$ を $\xi_y, \xi_z$ で積分した 5 本の関数 $G_k(x,\xi_x) = \iint \psi_k f\,d\xi_y d\xi_z$ を解く。

| $k$ | $\psi_k$ | 使い道 |
|---|---|---|
| 0 | $1$ | $\rho$, $u_x$, $P_{xx}$, $q_x$ |
| 1 | $\xi_y$ | $u_y$, $P_{xy}$, $q_y$ |
| 2 | $\xi_y^2 + \xi_z^2$ | $T$, $q_x$, $q_y$ |
| 3 | $\xi_y^2$ | $P_{yy}$, $q_y$ |
| 4 | $\xi_y(\xi_y^2 + \xi_z^2)$ | $q_y$ |

輸送項は $\xi_y, \xi_z$ を含まないので、各 $G_k$ は $\xi_x\,\partial_x G_k = \nu (G_k^S - G_k)$ を満たす。Shakhov の目標分布 $f^S$ は ($\xi_y, \xi_z$) について「多項式 × Gauss 関数」なので、その縮約 $G_k^S$ は $(\rho, u_x, u_y, T, q_x, q_y)$ の閉じた式になる($a = \xi_x - u_x$、$M_1 = (2\pi T)^{-1/2}e^{-a^2/2T}$、$A = (1-\Pr)/(5\rho T^2)$、$B_0 = a^2/T - 3$、$d = a^2 - T$。$R = 1$):

$$
\begin{aligned}
G_0^S &= \rho M_1\,[1 + A q_x a B_0]\\
G_1^S &= \rho M_1\,[u_y(1 + A q_x a B_0) + A q_y d]\\
G_2^S &= \rho M_1\,[(2T + u_y^2) + A q_x a (2d + u_y^2 B_0) + 2A q_y u_y d]\\
G_3^S &= \rho M_1\,[(T + u_y^2) + A q_x a (d + u_y^2 B_0) + 2A q_y u_y d]\\
G_4^S &= \rho M_1\,[(4u_yT + u_y^3) + A q_x a (4u_y d + u_y^3 B_0) + A q_y (4T(a^2+T) + 3u_y^2 d)]
\end{aligned}
$$

壁の Maxwell 分布の縮約も解析的($G_0 = n_w M_1(\xi_x; T_w)$、$G_1 = u_w G_0$、$G_2 = (2T_w + u_w^2)G_0$、…)。
これらの式は、縮約した目標分布のモーメントが $\rho, \boldsymbol u, T$、$(1-\Pr)\boldsymbol q$、等方な圧力を丸め誤差(1e-15 程度)で再現することで確かめた。

**この方式を選んだ理由**
1. 縮約は近似ではなく厳密なので、$\xi_y, \xi_z$ 方向の離散化誤差がゼロになる。クエット流の壁速度($y$ 方向、最大 $1\sqrt{RT_0}$)を速度格子で覆う必要もない。
2. 残る 1 次元の速度 $\xi_x$ を、半区間ごとの高次の求積で細かく(400 点)取れる。壁では $\xi_x = 0$ で分布関数が不連続で、0 付近に $|\xi_x|\ln|\xi_x|$ 型の特異性もあるので、ここの精度が参照解の精度を決める。3 次元のデカルト格子(区間中点の一様格子)では $\xi_x = 0$ の不連続のために 2 次精度にとどまり、$\Delta\xi = 2/3$ では $q_x, P_{xy}$ に 0.03%(Kn = 0.01)〜2%(Kn = 10)の誤差が出る(§5.6)。
3. 未知数は 5 × 801 節点 × 400 速度点 = 1.6×10⁶ で、1 ケース数秒で解ける。

### 3.2 速度格子($\xi_x$)
正の半区間 $(0, \xi_{max}]$ を、0 に向かって幾何級数的に細かくしたパネル(比 1/4)と幅一定のパネルに分け、各パネルに Gauss–Legendre 求積を置く。負の半区間は鏡映。$\xi_x = 0$ は点に含めず、パネルの境界にする(`src/ref1d/velocity.py`)。

| 水準 | $\xi_{max}$ | パネル幅 | GL 点数 | 0 付近の段数 | 点数 $N_v$ |
|---|---|---|---|---|---|
| v0 | 10 | 1 | 4 | 2 | 96 |
| v1 | 10 | 1 | 6 | 3 | 156 |
| v2 | 10 | 0.5 | 6 | 4 | 288 |
| **v3(本計算)** | 10 | 0.5 | 8 | 5 | 400 |
| v4 | 12 | 0.25 | 8 | 6 | 864 |

$\xi_{max} = 10\sqrt{RT_0}$ は最も高温の $T = 1.5T_0$ でも熱速度の 8.2 倍で、裾の切り捨ては $e^{-33}$ 程度。3 次元ソルバーと同じ点配置の一様な区間中点格子(`midpoint`)も選べる(§5.6)。

### 3.3 空間離散化(短特性線法)
- 節点 $x_i = \tfrac12(1 - \cos(\pi i/N))$($i = 0..N$、壁の上にも節点)。壁付近の間隔は $\pi^2/(4N^2)$($N = 800$ で 3.9e-6)、中央で $\pi/(2N)$。クヌーセン層の $x\ln x$ 型の特異性を、壁に向かって 2 乗で細かくなる格子で解像する。
- 衝突時間座標 $s(x) = \int_0^x \nu\,dx'$ を使うと、各速度点で $\xi_x\,dG/ds = G^S - G$。$\Delta s$ は $\nu$ の 3 次補間を各セルで積分して求める。
- 各セルで $G^S$ を $s$ の 3 次多項式(節点 $i-1..i+2$ の Lagrange 補間、壁の近くでは内側にずらす)で表し、セル内で厳密に積分する:
  $$G_{out} = G_{in}\,e^{-\tau} + \sum_a W_a(\tau)\,G^S_a,\qquad \tau = \Delta s/|\xi_x|,\qquad W_a = \sum_m V^{-1}_{ma}E_m(\tau),\quad E_m(\tau) = \int_0^\tau (t/\tau)^m e^{-t}dt$$
  $\xi_x > 0$ は左から右へ、$\xi_x < 0$ は右から左へ掃引する(`kernels.sweep`)。
- 性質: 無条件に安定(CFL 条件なし)。自由分子極限($\nu \to 0$)で厳密。衝突が支配的な極限($\tau \to \infty$)では $G \approx G^S - \xi_x\,dG^S/ds + \dots$ となり、Chapman–Enskog の 1 次(NS の応力・熱流束)を補間の精度で再現する。
- 依頼で想定されていた「2 次精度の風上差分」の代わりにこの方式を選んだのは、(1) 小さい $|\xi_x|$ で格子より薄い境界層があっても厳密に積分できる、(2) 高次(観測された収束次数は約 4、§5.5)で、$q_x, P_{xy}$ の相対 3e-8 以下の精度が $N = 800$ で得られるため。

### 3.4 拡散反射の境界条件と流入密度
1 回の掃引で、壁からの流入をゼロとした解 $G_A$ を求める。壁から放出された分子の寄与は解析的に $n_L H_L(\xi_x)e^{-s(x)/\xi_x}$($\xi_x>0$)、$n_R H_R(\xi_x) e^{-(s(L) - s(x))/|\xi_x|}$($\xi_x<0$)なので、
$G = G_A + n_L B_L + n_R B_R$。各壁の正味質量流束(離散速度空間の和)をゼロにする 2 元連立 1 次方程式

$$
n_L j_L + a_L + n_R b_L = 0,\qquad a_R + n_L b_R - n_R j_R = 0
$$

を掃引のたびに解く($j$: 単位密度の壁 Maxwell 分布が気体に入れる質量流束、$a$: $G_A$ が壁に運ぶ質量流束、$b$: 反対側の壁から減衰して届く分の流束。すべて離散速度の和)。流入密度を前の反復から持ち越す(遅れ評価)のではなく、掃引の中で厳密に連立させるので、自由分子に近い領域でも反復が数回で収束する。

### 3.5 全質量
拡散壁だけで囲まれた定常問題では、全質量は方程式からは決まらない(条件として与える)。各掃引の後に $G$ を定数倍して $\int_0^1\rho\,dx = 1$(区分 3 次補間の積分)にする。収束した解ではこの倍率は 1。

### 3.6 反復と収束判定
- 節点の巨視量 $X = (\rho, u_x, u_y, T, q_x, q_y)$ の不動点問題 $X = \Phi(X)$($\Phi$: 目標分布 → 掃引 → 流入密度 → モーメント → 規格化)を、Anderson 加速(履歴 100、最小二乗)で解く。最初の 2 回は単純反復。
- 収束判定: $\max|\Phi(X) - X| < 10^{-12}\times\max(|T_R - T_L|, |u_R - u_L|)$ または $< 10^{-14}$(O(1) の量の丸め誤差の下限)。
- 反復回数: Kn ≥ 1 で 6〜15 回、Kn = 0.1 で約 35 回、Kn = 0.01 で約 200〜230 回(本計算の格子で 5〜6 秒)。Kn = 0.0025 では 3,000〜6,000 回(3〜4 分)。

### 3.7 保存則の離散的な扱い
- **衝突項**: 目標分布の縮約は解析式で、$\xi_x$ 方向の求積は Gauss 関数に対して丸め誤差の精度なので、$\sum_j w_j\psi(\xi_j)(G^S_j - G_j)$ は質量・運動量・エネルギーについて 1e-15 程度でゼロ(確認済み)。保存のための補正はしていない。
- **壁**: 正味質量流束は離散速度空間で厳密にゼロ(§3.4)。運動量・エネルギーは壁とやり取りする(物理)。
- **輸送**: 短特性線法は有限体積法の意味では保存形ではないので、質量流束、$P_{xx}$、$P_{xy}$、$Q_{tot}$ は離散化誤差の範囲でだけ一様になる。本計算の格子で、質量流束 ≤ 3e-8、$P_{xx}$ の場所によるばらつき ≤ 2e-11、$P_{xy}$ のばらつき ≤ 5e-7(相対)、熱伝導の $q_x$ のばらつき ≤ 2.1e-6(相対)。このばらつきを誤差の指標として使う。
- **全質量**: 規格化で厳密(§3.5)。
- 要約の `qx_mean`, `Pxy_mean` は区間 [0,1] での平均(区分 3 次補間の積分)。厳密解は一様なので、平均が最もよい推定になる(壁での値との差はばらつきの範囲)。

## 5. 検証

### 5.1 自由分子極限(解析解)
自由分子流では、壁から放出された半 Maxwell 分布がそのまま反対側の壁に届く。零質量流束 $n_L\sqrt{T_L} = n_R\sqrt{T_R} \equiv C$ と平均密度 $(n_L+n_R)/2 = 1$ から、

$$
q_x = \sqrt{2/\pi}\;C\,(T_L - T_R) - u_yP_{xy}\ \text{(熱伝導では第 2 項なし)},\qquad
P_{xy} = \frac{C\,(u_L - u_R)}{\sqrt{2\pi}},\qquad
T = \sqrt{T_LT_R}\ \text{(熱伝導)},\quad T = 1 + u_w^2/3\ \text{(クエット流)}
$$

(一般形は `analytic.free_molecular`)。$\mathrm{Kn} = \infty$($\nu = 0$)で解くと、$q_x$、$P_{xy}$、$T$、$\rho$、$n_w$ が解析解と丸め誤差の範囲(相対 1e-13 以下)で一致した。大きい Kn での相対差(`results/verification/free_molecular.csv`、図 `verification_free_molecular.png`):

| Kn | heat_lin $q_x$ | heat_nl $q_x$ | couette_lin $P_{xy}$ | couette_nl $P_{xy}$ |
|---|---|---|---|---|
| ∞ | +9.6e-15 | -8.3e-14 | +1.7e-16 | 0 |
| 1e6 | -5.48e-07 | +1.19e-07 | -7.75e-07 | +1.34e-07 |
| 1e5 | -5.49e-06 | -1.31e-07 | -7.77e-06 | -3.57e-07 |
| 1e4 | -5.50e-05 | -1.45e-05 | -7.78e-05 | -2.05e-05 |
| 1e3 | -5.49e-04 | -2.72e-04 | -7.78e-04 | -3.71e-04 |
| 100 | -5.35e-03 | -3.76e-03 | -7.62e-03 | -5.15e-03 |
| 10 | -4.63e-02 | -3.94e-02 | -6.66e-02 | -5.57e-02 |

線形域のケースでは差がちょうど $1/\mathrm{Kn}$ に比例して 0 に近づく。非線形のケースでは $(a + b\ln\mathrm{Kn})/\mathrm{Kn}$ の形になる(壁付近の密度の $(\ln \mathrm{Kn})/\mathrm{Kn}$ 型の補正が、全質量の規格化を通して $q_x, P_{xy}$ にも入るため。線形域では密度の補正が反対称で平均に効かない)。この対数特異性は $|\xi_x| \approx \nu L$ にあるので、この検証だけ $\xi_x = 0$ 付近を 12 段まで細かくした速度格子を使った(段数 5 の v3 では Kn ≥ 1e5 で解像しきれずに形が崩れる。本計算の範囲 Kn ≤ 10 では $\nu L \ge 0.1$ なので影響はない)。

### 5.2 すべり係数・温度跳躍係数(線形化した問題からの逆算)
摂動 $\varepsilon = 10^{-4}$ の熱伝導・クエット流を解き、大きい δ で厳密に成り立つ関係(線形化した問題ではバルクの解が NSF に一致し、クヌーセン層どうしの干渉は δ について代数的より速く小さくなる)

$$
\frac{q_x}{q_{x,fm}} = \frac{5\sqrt\pi/(4\Pr)}{\delta + 2\zeta_T},\qquad \frac{P_{xy}}{P_{xy,fm}} = \frac{\sqrt\pi}{\delta + 2\sigma_P}
$$

から係数を逆算した(平均自由行程 $\ell = \mu\sqrt{2RT_0}/p_0$ 単位、`results/verification/slip_jump.csv`)。

| モデル | 量 | Kn = 0.02 | 0.01 | 0.005 | 文献値 |
|---|---|---|---|---|---|
| BGK | $\zeta_T$ | 1.3027157 | 1.3027160 | 1.3027157 | 1.302716 [GS2010 Table 6] |
| BGK | $\sigma_P$ | 1.0161915 | 1.0161916 | 1.0161919 | 1.016191 [SS2002 Table I] |
| S | $\zeta_T$ | 1.9540735 | 1.9540740 | 1.9540736 | 1.954073 [GS2010 Table 6] |
| S | $\sigma_P$ | 1.0183724 | 1.0183725 | 1.0183721 | 1.018372 [SS2002 Table I] |

文献値と 6〜7 桁一致した。S モデルの温度跳躍係数は BGK の値の $1/\Pr$ 倍(熱伝導率基準の平均自由行程では同じ値)になる一方、**速度すべり係数は BGK と異なる**(1.018372 と 1.016191)。クエット流では $q_y$ がクヌーセン層で一様でなく、Shakhov の補正項 $(\boldsymbol c\cdot\boldsymbol q)$ がせん断の問題に効くためで、本ソルバーはこの差を正しく再現している。

### 5.3 連続体に近い極限(NSF + 1 次のすべり・温度跳躍)
NSF 方程式($u_x = 0$、$p$ 一様、$\mu, \kappa \propto T^\omega$)と 1 次のすべり・温度跳躍条件 $u - u_w = \sigma_P\ell\,\partial_n u$、$T - T_w = \zeta_T\ell\,\partial_n T$($\ell$ は壁での局所値、係数は S モデルの文献値)の解を `scipy.integrate.solve_bvp` で求め(`analytic.nsf_slip`)、非線形のケースも含めて比べた(`results/verification/nsf.csv`、図 `verification_nsf.png`)。

| 0.1 | +2.03e-04 | -1.43e-02 | -7.44e-05 | -1.49e-02 | +1.6e-02 | -3.06e-01 | +6.36e-02 |
| 0.05 | -4.29e-05 | -5.44e-03 | -5.98e-05 | -6.07e-03 | +5.4e-03 | -1.81e-01 | +3.16e-02 |
| 0.02 | -9.97e-06 | -1.08e-03 | -1.29e-05 | -1.31e-03 | +1.0e-03 | -8.11e-02 | +1.31e-02 |

- クエット流の壁での $q_x$(参考)だけは差が Kn に比例する。対称性から $Q_{tot} = 0$ なので壁での $q_x = -u_y(\text{壁})P_{xy}$ であり、運動論の壁での気体速度(壁の節点の値)のすべりが、クヌーセン層のため NSF の外挿したすべり速度の約 7 割になることによる。例えば couette_lin の Kn = 0.01 では、壁の $q_x$ の差 +7.08e-3(`nsf.csv`)が、すべり速度 1.553e-3(運動論)と 2.247e-3(NSF)から求めた壁での気体速度の比 1.0071 と一致する。誤差ではない。

## 6. 精度の目安

S3で `Problem(accommodation=alpha)` と `run_cases.py --accommodation alpha` を追加した。0<α≤1、両壁に共通のMaxwell適応係数。既定1の計算順を保つ。部分適応では速度対ごとに壁間の鏡面往復を解析的に加え、壁の密度の2元連立系を解く。自由分子極限の熱流束・せん断応力は拡散壁の値の `α/(2−α)` 倍。下記の既存の誤差表はα=1の評価であり、部分適応の誤差をそのまま保証しない。S3の部分適応の格子比較と3次元比較は `docs/phase8_s3_report.md` と `runs/phase8/s3/ref1d/` に記録する。

`tests/test_maxwell.py` はα=1のS3前のgit版とのビット一致、α=0.2・0.5の自由分子極限、有限Knでの壁の零質量流束、不正αを検査する。`nsf_slip` の既定の文献係数は完全拡散壁専用であり、α<1には自動適用しない。

部分適応の結果を既存の参照値と分けて保存する場合は、例えば `run_cases.py --accommodation 0.5 --tag _a0p5` と指定する。

本計算の格子(N = 800、速度格子 v3、3 次補間)での誤差の目安(§5.5 の N = 1600、v4 との差から。いずれも Kn = 0.01 が最大):

| 量 | 誤差の目安 |
|---|---|
| $q_x$(熱伝導、区間平均)、$P_{xy}$ | 相対 3e-8 以下(Kn ≥ 0.1 では 2e-9 以下) |
| 壁での $q_x$(熱伝導の壁の値、クエット流の壁の熱流束) | 相対 2e-6 以下(Kn ≥ 0.1 では 2e-8 以下) |
| 壁での温度跳躍・速度すべり | 絶対 3e-8 以下($T_0$、$\sqrt{RT_0}$ 単位) |
| 分布の節点値 | 内部で相対 1e-7 程度、壁の近くで 1e-6 程度 |
| 反復の打ち切り | $10^{-12}$ × 摂動の大きさ(相対 1e-10 程度) |

要求の「相対 1e-4」に対して 2 桁以上の余裕がある。モデル自体(Shakhov、拡散反射、べき乗則の粘性)との差は含まない(参照解はこのモデルの解である)。

## 7. 3 次元ソルバーとの比べ方

### 7.1 条件の合わせ方
- **計算領域**: 平板間の薄い直方体($x$ が板の法線、$0 \le x \le L$)。側面の境界は次のとおり。
  - 熱伝導: 側面はすべて鏡映(対称面)でよい(厳密解は $\xi_y, \xi_z$ について対称)。
  - クエット流(壁が $y$ 方向に動く): **$y$ に垂直な側面は周期境界が必要**。鏡映面は $u_y = 0$ を強制するので使えない。$z$ に垂直な側面は鏡映でよい。
- **気体**: Shakhov、$\Pr = 2/3$、$\mu \propto T^{0.66}$。SI で入力する場合は $T_0 = (T_L+T_R)/2$ と $L$ を決め、初期の一様な密度を $\rho_0 = \mu(T_0)\sqrt{\pi RT_0/2}\,/\,(\mathrm{Kn}\,RT_0\,L)$ にする($\mu_0$ の値自体は任意で、Kn だけが効く)。
- **全質量**: 拡散壁だけの閉じた領域なので、定常解の全質量は初期値で決まる。3 次元ソルバーの反復が全質量を保存しない場合(擬似時間刻みが無限大の反復など)は、全質量の監視か規格化が要る(本ソルバーは §3.5 のとおり毎回規格化する)。
- **速度格子**: 法線方向は $\pm 10\sqrt{RT_0}$ で足りる($T \le 1.5T_0$ でも熱速度の 8 倍以上)。

### 7.2 比べる量と参照値
| 3 次元ソルバーの量 | 参照値 | 注意 |
|---|---|---|
| 熱流束 $q_x$(熱伝導) | `summary.csv` の `qx_mean` | 厳密解は一様。セル値の平均か、壁面のエネルギー流束と比べる |
| せん断応力 $P_{xy}$(クエット流) | `Pxy_mean` | 一様 |
| クエット流の壁面のエネルギー流束 | `Qtot_mean`(対称なので 0)、`qwall_L/R`(壁の座標系)、`qx_wallL/R`(気体の速度で定義) | 定義の違いは §2.2 |
| 分布 $\rho, u_y, T, p, q_x, q_y, P_{ij}$ | `profiles/<case>_Kn<..>.csv` | 801 個の節点(余弦分布)の値。3 次元のセル中心へは 3 次スプラインで補間する。壁から 1〜2 平均自由行程はクヌーセン層で勾配が急(壁で $x\ln x$ 型)なので、セル平均値と節点値の差が出やすい |
| 壁での温度跳躍・速度すべり | `T_jump_*`, `slip_*`, `T_gas_*`, `uy_gas_*` | 壁面上の分布(流入する壁 Maxwell 分布 + 流出する分布)のモーメント。壁に接するセルの中心の値とは別物なので、境界面の分布 $f_b$ から計算して比べる |
| 壁の流入密度 | `n_wall_L/R` | 論文の付録 A.1 の $\rho_{\Gamma,b}$(単位 $\rho_0$) |

### 7.3 速度格子による差の切り分け
3 次元ソルバーの速度格子は $\xi_x$ 方向が区間中点の一様格子($\Delta\xi = 2/3\sqrt{RT_0}$)。$\xi_x = 0$ で分布関数が不連続なため、この格子だけで $q_x, P_{xy}$ に 0.03%(Kn = 0.01)〜2%(Kn = 10)、壁での温度跳躍・すべりに絶対 0.02〜0.03(Kn = 10)の差が出る(§5.6)。
`summary_vmid30.csv` と `profiles_vmid30/` は、同じ $\xi_x$ の格子(30 点、$\pm 10$)で空間だけを収束させた値である($\xi_y, \xi_z$ は解析的に積分。管ケースの 24 点・$\pm 8$ の格子でも結果は同じになることを確かめた)。
- 3 次元の結果 − `summary_vmid30.csv` = 3 次元ソルバーの空間離散化と実装による差
- `summary_vmid30.csv` − `summary.csv` = 速度格子($\Delta\xi = 2/3$)による差

## 9. 注意と未解決の点
- **小さい Kn での反復**: Anderson 加速だけなので、反復回数は Kn = 0.01 で約 200、0.005 で約 700、0.0025 で 3,000〜6,000 と急に増える。Kn < 0.005 を本格的に使うなら、マクロ方程式による合成加速(GSIS と同じ考え方)を入れるとよい。Kn = 0.01〜10 の本計算には十分。
- **非線形の文献値**: $\omega = 0.66$ の非線形ケースそのものの文献値は見つからなかった。非線形の正しさは、自由分子極限・NSF 極限(どちらも非線形のまま比較)と、剛体球($\omega = 0.5$)の非線形 Shakhov の表 [M2009](3 桁)で確かめた。
- **分布関数の負値**: Shakhov の目標分布は、熱流束が大きいと速度の裾で負になりうる(モデルの性質)。本ソルバーは補正をしていない(論文の負値の補正は GSIS の補正後の $f$ に対するもので、目標分布に対するものではない)。
- **壁での値の定義**: 本参照解の壁での値は壁面上の分布のモーメントで、クヌーセン層のため壁から少し離れた値とは大きく違う(例えば壁での気体のすべり速度は、NSF で外挿したすべり速度の約 7 割)。3 次元ソルバーと比べるときは、同じ定義の量(境界面の分布のモーメント)を使う。
- **出力の精度**: 分布の CSV は 13 桁、要約の CSV は 16 桁で書いている。
